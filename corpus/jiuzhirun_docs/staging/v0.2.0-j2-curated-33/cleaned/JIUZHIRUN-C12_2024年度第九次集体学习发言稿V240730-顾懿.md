# 理论学习发言

电广传媒党委理论学习中心组（扩大）

2024年第九次集中学习研讨会

--上海久之润 顾懿发言稿（2024年8月2日）

尊敬的艳忠书记、各位领导、各位同事：

大家好！非常荣幸能够在本次电广传媒党委理论学习中心组（扩大）集中学习研讨会上做交流发言。通过前面艳忠书记对党的二十届三中全会精神的领学，让我进一步增进了党的理论水平，加深了对党的指导思想的理解。党的二十大三中全会是在新时代新征程上，中国共产党坚定不移高举改革开放旗帜，紧紧围绕推进中国式现代化进一步全面深化改革而召开的一次十分重要的会议。会前我和我的团队认真学习了《中共中央关于进一步全面深化改革推进中国式现代化的决定》，这份《决定》为我们指明了前行的方向，《决定》中提到“中国式现代化是物质文明和精神文明相协调的现代化”，对于如何做好“深化文化体制机制改革”做了明确部署和要求,下面我想结合自己实际工作谈一些自己的感想和认识:

（1）坚持文化自信：通过游戏讲好中国故事

习近平总书记曾在2023年10月全国宣传思想文化工作会议上就明确指出，要着力赓续中华文脉、推动中华优秀传统文化创造性转化和创新性发展。这次《决定》中关于“深化文化体制改革”又做了明确要求，“必须增强文化自信”。作为游戏行业的从业者，我们肩负着将中华优秀传统文化融入游戏的责任，通过游戏这一载体，积极提升年轻一代对中华文化的认同感和自豪感。同时，我们更要将这种文化自信融入国产游戏的出海过程中，不论是弘扬传统文化还是其他内容形式，通过游戏讲好中国故事，增强国际社会对中国文化的认同感。我想借今天这个机会，给各位领导汇报下，久之润目前正在研发一款名为《东方》的手游，这是一款以抗美援朝为故事背景的红色题材游戏。我们希望通过这款游戏，再现那段波澜壮阔的历史，弘扬革命文化，传递爱国主义精神。

（2）坚持科技创新：科技与游戏的深度融合

近年来，AIGC（人工智能生成内容）技术在游戏行业的应用取得了显著进展，推动了文化产业的创新与发展，为游戏行业带来了无限可能。例如，网易游戏的《蛋仔派对》通过将UGC（用户生成内容）与AIGC有机结合，开辟了更多面向不同内容受众的应用场景。这种融合不仅提升了创作效率，还为玩家提供了更丰富的互动体验。通过科技与游戏的深度融合，文化产业不仅能够实现内容的多样化和个性化，还能提升用户体验，推动文化软实力的提升。久之润作为一家互联网游戏企业，始终紧跟这股科技浪潮，致力于将创新科技融入产品设计中。近期，我们与湖南芒果融创合作，利用Vicon动捕直播技术实现了劲舞团游戏人物的实时互动直播效果，后续久之润将在此基础上，持续增强《劲舞团》IP在抖音平台曝光，积极探索虚拟人业务的可能性。

（3）坚持以人为本：重视游戏人才的培养和团队建设

久之润坚持以人为本的理念，通过持续的人才培养和团队建设，致力于打造更具影响力和竞争力的游戏作品，为推动文化产业的可持续发展贡献力量。我们通过内部培养与外部在职培训相结合的培养体系，以实现公司核心人才队伍的可持续发展。在2023年度我们举办了4场内训，参加了12场外训和4场在线视频培训，同时，我们实行核心项目组绩效奖金激励分配、核心人才培养补贴以及年度绩效奖金分配等多项激励措施，以激励和培养优秀的核心人才。通过以上措施我们努力保持团队的创造力和竞争力，为久之润的长远发展奠定坚实基础。

（4）坚守网络生态安全：守护网络生态，责任重于泰山

久之润作为一家国有互联网游戏企业，我们深知守护网络生态的重要性。《决定》中提到的健全网络综合治理体系，我们作为互联网游戏行业的从业者，参与者，更有责任去严格落实相关法律法规，守护网络生态。同时，我们将持续贯彻落实未成年人网络保护工作体系各项举措，保障青少年健康成长环境。通过这些措施，我们坚守网络生态的底线，确保游戏产业的健康发展，为社会稳定与进步贡献我们的力量。

在当前电广传媒实施“文旅+投资”大战略、加速形成“文化+科技”新质生产力的关键时期，久之润不仅肩负着贡献收入利润的责任，更要积极投身于助攻“文旅+投资”大战略，我们希望能够借助这次二十届三中全会带来的改革机遇，充分发挥与海外多家IP巨头的良好关系，引入更多像“熊本熊X万楼”这样的成功案例，将知名IP与文旅相结合，探索更多创新路径，为电广传媒在文旅产业的创新和发展贡献我们的力量。

作为一名国企干部，我将深刻领会党的二十届三中全会精神，以务实的作风、饱满的状态、昂扬的斗志投入到工作中。我将带领我的团队，聚焦改革目标，明确任务，夯实举措，积极担当，不断探索新路径，为推进文化体制改革贡献久之润的一份力！

就在上周，我很荣幸地被评选为中国音像与数字出版协会游戏产业研究专家委员会的委员。这份荣誉既是肩负的责任，更是一份使命。我将全力以赴，为游戏产业的发展贡献智慧和力量，为久之润创造更大的价值。

谢谢大家！
