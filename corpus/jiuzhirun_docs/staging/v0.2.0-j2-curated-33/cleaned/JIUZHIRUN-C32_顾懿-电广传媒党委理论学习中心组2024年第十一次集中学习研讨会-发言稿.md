# 理论学习发言

电广传媒党委理论学习中心组（扩大）

2024年第十一次集体学习会议上的发言

上海久之润公司总经理  顾懿

（2024年12月20日）

尊敬的王书记、付总、各位领导、各位同事：

大家好！首先，感谢各位领导的信任与支持，我有幸在这里与大家共同学习中央经济工作会议精神。会前我认真深入自学习近平总书记在中央经济工作会议上的重要讲话精神，这次我主要汇报久之润经营班子对于本次中央经济工作会议的一些理解，同时跟大家分享一下最近观察到的一些行业变化，最后是谈一下久之润2025年的一些初步构想。

本次中央经济工作会议明确指出：“当前经济运行总体平稳、稳中有进。”对久之润及互联网游戏行业而言，这一基调为我们的发展奠定了坚实基础。在外部环境复杂多变、行业竞争日趋激烈的背景下，中国经济展现出强大的韧性和活力，为我们提供了一个相对稳定的环境。这种“稳”的大局不仅为我们持续推进业务发展提供了信心，也为我们探索新的增长点创造了更多可能。会议还强调，“党中央集中统一领导是做好经济工作的根本保证。”只有在党中央的正确领导下，才能有效应对各种挑战和风险，确保经济工作始终沿着正确的轨道前行。作为电广传媒的全资子公司，我们将坚决贯彻电广传媒党委的决策部署，坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻党的二十大精神，牢牢把握“稳中求进”的工作总基调。这不仅是我们做好各项工作的根本原则，也是我们实现长期稳定经营的核心保障。

在学习中央经济工作会议精神的基础上，我们也密切关注到了行业中的一些新兴趋势，这些趋势与我们久之润发展息息相关，值得我们重视。

1、短剧市场收入超过电影票房

今年以来，短剧市场收入已超越传统电影票房，截至2024年上半年，我国微短剧用户规模已经超过5.76亿，占据了全体网民的半壁江山，比例高达52.4%。值得注意的是，短剧的兴起不仅激活了大量中老年用户的互联网消费潜力，也与我们《劲舞团》的核心用户群——以80后为主的社交娱乐群体——高度契合。展望明年，我们计划结合与芒果融创的数字人直播合作项目，通过更加丰富的内容形式精准触达目标用户，既满足现有用户的多元需求，又吸引更多潜在用户，进一步拓展收入增长的新空间。

2、小游戏的投放规模超越手游

小游戏的市场规模已经达到398.36亿元，并且同比增长99.18%。这种现象表明，小游戏在市场上的巨大潜力，尤其是在女性用户群体中的表现尤为突出。小游戏不再仅仅依赖传统的游戏玩法，而更多依靠“情绪价值”来驱动用户的付费和活跃度。明年我们将进一步加大对小游戏赛道的布局力度，目前我们《劲舞之星》APP版本和小游戏版本正处于研发中，通过强化社交互动和提升用户体验，为业务发展注入更多活力。

3、直播打赏流水超过了游戏

近年来，直播行业的迅猛发展为我们带来了新的机遇。统计数据显示，今年直播打赏（不含电商）的流水已超越了游戏，成为新的消费趋势。经过前期多款产品的试探和测试，我们的直播互动娱乐产品《劲舞之星》和《劲乐派对》已经跻身抖音热度榜前十。展望明年，我们计划推出《劲舞之星》升级版及更多新产品，进一步加强与MCM机构的合作，充分挖掘直播和互动娱乐的潜力，不仅巩固现有市场份额，还将进一步扩展我们的影响力，探寻久之润业务新的增长点。

结合本次中央经济工作会议提出的“坚持稳中求进工作总基调”，我们拟定了2025年的工作重点：

1、稳收入：保持现有收入和业务稳定

在当前的经济环境下，我们首先要稳住现有业务，确保收入来源的稳定。我们将继续坚持精品化长线运营，依托现有核心产品，确保《劲舞团》等游戏的收入基本盘不受影响，通过精细化运营和优化产品结构，增强市场适应性和抗风险能力。

2、稳利润：持续降本增效与探索增长点

在稳住基本盘的同时，我们要确保利润的稳定增长。我们将继续通过持续的降本增效来提升运营效率，降低成本，确保每一项投入都能够创造最大的回报。同时我们将加强新业务的布局，探索短剧、小游戏和直播等新兴市场，寻找利润增长的新动能。

3、稳团队：保障团队稳定与员工成长

稳定的团队是久之润持续发展的基础。2025年，我们将进一步优化管理架构，提升团队效率和凝聚力，确保管理层及业务骨干的稳定。同时我们将完善福利制度，关注员工身心健康和职业发展，提供更好的发展空间，确保每位员工能够与公司共同成长，增强员工的获得感、幸福感和安全感，为久之润长远发展提供强大支持。

总的来说，2025年，我们将坚持“稳中求进、以进促稳”的工作总基调，在保持现有收入和利润的同时，积极推动创新及业务调整，以持续提升市场竞争力。在实现稳收入、稳利润、稳团队的同时，为久之润未来的持续增长奠定坚实基础，为电广传媒的高质量发展贡献久之润的力量，我的汇报完毕，谢谢大家！
