# 纪检工作总结

2025年度上半年纪检监察工作总结

2025年上半年，在电广传媒党委和纪委的坚强领导下，上海久之润纪检工作严格按照上级统一部署，以扎实开展“深入贯彻中央八项规定精神学习教育”为核心任务，聚焦主责主业，认真履行监督职责，确保上级各项工作要求在久之润得到全面落实。现将主要情况汇报如下：

上半年主要工作

（一）闻令而动，认真完成学习教育各项“规定动作”

我们第一时间传达学习了电广传媒关于学习教育的系列通知和任务清单，组织党员干部深入学习习近平总书记关于作风建设的重要论述和中央八项规定及其实施细则精神。同时，按照要求组织党员干部收看警示教育视频，通过学习和警示，切实增强了干部职工的纪律意识和规矩意识。

（二）对标对表，扎实开展问题自查自纠

严格按照上级通知要求，组织领导班子和干部职工，对照《违反中央八项规定及其实施细则精神问题清单》和《隐形变异的作风问题清单》两个清单，逐项进行了“过筛子”式的自查自纠。同时，针对省纪委监委牵头部署的“在单位内部食堂、培训中心违规公款吃喝”及“借调研培训等名义公款旅游”两个立行立改问题，我们开展了专项排查，经核，久之润不存在相关情况。在自查中，我们发现久之润存在“对员工因超时工作带来的身心疲惫和家庭影响关注不足”的问题，并本着实事求是的原则，将其作为“漠视侵害群众利益”的具体表现列入了问题清单。

（三）立行立改，积极推动查摆问题整改落实

针对自查发现的问题，我们迅速建立了《学习教育集中整治台账》 ，明确由久之润主要负责人顾懿同志牵头，制定了“完善加班管理制度、规范加班审批流程、加强人文关怀”等具体整改措施。目前，相关整改工作正在有序推进中 。

（四）从严从实，协助落实上级监督谈话制度。

上半年根据电广传媒纪委的统一部署，我们积极配合并推动落实上级“一把手”、纪委书记同下级“一把手”的监督谈话制度 ，按要求报送了谈话基础材料，层层压实责任，切实加强了对公司“关键少数”的监督。

二、存在的问题与不足

在完成上级交办任务的过程中，我们也清醒地认识到自身工作还存在一些不足：

一是监督方式需要紧跟业务变化。随着久之润新业务的开展，如何将传统的监督方式有效应用于新业态，确保监督无死角，是我们面临的现实挑战。

二是纪检工作与业务工作的融合需要磨合。如何让纪检监督更好地嵌入业务流程前端，在风险防范上发挥更大作用，还需要我们在实践中不断探索。

三是举一反三、建章立制的工作仍需加强。针对发现的问题，虽然做到了及时整改，但在完善长效机制、从制度上根本解决问题方面，还需投入更多精力。

三、下半年工作要点

下半年，我们将继续严格按照电广传媒纪委的工作部署，重点做好以下工作：

一是持续抓好问题整改，紧盯上半年查摆出的问题，督促整改措施全部落实到位。

二是努力提升监督能力，将加强对新业务模式的学习和研究，积极探索适应新业态的监督方法，提升纪检工作的专业性和有效性。

三是推动完善内部制度，结合整改工作，推动相关职能部门修订完善内部管理制度，力求从源头上堵塞漏洞，巩固学习教育成果。

久之润纪检工作将始终坚持以电广传媒党委及纪委的要求为导向，聚焦落实、注重实效，为久之润的平稳健康发展提供坚实的纪律保障。
