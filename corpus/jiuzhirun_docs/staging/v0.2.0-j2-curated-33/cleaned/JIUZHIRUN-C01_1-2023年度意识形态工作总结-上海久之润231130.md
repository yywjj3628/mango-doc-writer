# 意识形态工作总结

2023年度意识形态工作总结

作为党管国企互联网游戏公司，上海久之润始终坚定践行社会主义核心价值观，坚决贯彻党的领导，遵循湖南电广传媒党委的坚强指引，牢牢把握意识形态工作方向。2023年，久之润紧密围绕意识形态工作核心任务，在相关领域积极推进各项工作。现就久之润在这一时期意识形态工作进行认真总结，并对存在不足之处进行深入剖析，汇报如下：

2023年久之润在意识形态领域的主要工作

2023年，在电广传媒党委的正确领导下，上海久之润认真贯彻落实习近平总书记关于网络强国的重要思想和党的二十大精神，以习近平新时代中国特色社会主义思想为指导，弘扬社会主义核心价值观，营造良好的网络文化环境，同时也为企业的健康发展提供了良好的保障：

1、组织领导的强化

上海久之润积极响应电广传媒的意识形态工作要求，将其紧密融入企业生产经营各环节，全面执行相关工作。由久之润总经理顾懿作为意识形态工作的主要负责人，亲自主持各项工作的开展。通过制定明确的工作方案、定期召开管理层例会、强化风险研判机制，全面推动了意识形态工作的有序开展。

2、加强思想教育，勇于承担社会责任

为提升员工理论素养和思想引导，久之润今年开展了一次以意识形态专题培训为主题的专题党课，旨在深化员工的党性教育，增强员工的思想认同。久之润一直秉持着将社会效益放在首位的理念，并不断努力实现社会效益和经济效益的有机统一。在2022年的“大上海保卫战”中，久之润积极投身抗疫工作，为全市的抗疫大局贡献了力量。获得了上海市经济和信息化委员会的高度认可，并为此向久之润发出了感谢信。这一举动无疑是对久之润在承担社会责任方面的努力所给予的充分肯定和表彰。

3、网络宣传工作的规范管理

上海久之润在新媒体账号编审、内容发布等方面，严格按照《久之润新媒体账号编审制度》要求进行管理。所有账号在新媒体管理平台备案登记，确保了新媒体宣传工作的规范和有序进行。同时，久之润还根据要求制定了户外广告宣传三审制，进一步加强了新媒体账号及官网平台的内容管理。

二、分析不足之处

上海久之润2023年意识形态工作中取得一定成绩，为久之润的发展提供了有力的保障。然而，我们也清醒地认识到存在的问题和不足之处。因此，我们要进一步加强意识形态工作，提高工作的质量和水平。

1、新兴媒体管理不能放松

尽管久之润已将名下各平台新媒体账号进行了系统性的统计和梳理，但整体更新和录入仍不够及时准确，例如部分账号UID存在错误等问题，我们将进一步完善新媒体账号编审制度及录入更新流程，规范账号的内容发布和管理，做到企业名下各平台新媒体账号有序管控。

2、强化舆论把控能力

在新形势下，久之润需要进一步增强对舆论引导的本领，增加正面宣传的力度和效果，减少负面舆论的影响和危害。加强对意识形态工作中负面舆情的预警和处理机制，提高对舆论引导的灵活性和主动性，以更好地引导舆论走向正面。尤其是在官网评论区的舆论把控能力要进一步提升。

三、下一步工作打算

在未来，久之润将继续深入贯彻湖南电广传媒的意识形态工作部署，不断创新工作模式，加强对新兴媒体的应用和引导管理，提升引导舆论的本领，确保意识形态工作的全面深入开展，为企业的健康发展提供坚实基础。
