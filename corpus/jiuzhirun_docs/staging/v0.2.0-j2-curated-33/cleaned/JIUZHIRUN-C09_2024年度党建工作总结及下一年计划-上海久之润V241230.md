# 党建工作总结

中共上海久之润信息技术有限公司支部委员会

2024年度党建工作总结及下一年计划

2024年是深入学习贯彻党的二十大精神的关键之年，在电广传媒党委的坚强领导下，久之润党支部以习近平新时代中国特色社会主义思想为指导，深入贯彻落实党的全面领导和全面从严治党的战略部署，强化基层党组织建设，进一步提升基层党组织的政治引领作用，现将2024年党建工作总结如下：

一、2024年度党建工作情况

1、扎实开展党纪学习教育活动

2024年，上海久之润党支部全面贯彻落实党的二十大和二十届二中、三中全会精神和习近平总书记考察湖南重要讲话精神，认真学习《中国共产党纪律处分条例》等党内法规。通过组织专题学习会、主题党日等形式，引导党员干部深入领会习近平总书记关于全面从严治党的重要论述，不断提高政治判断力、政治领悟力、政治执行力。在此基础上，充分利用“清风芒果”公众号，积极转发“党风党纪每日一课”等帖子，进一步引导党员干部增强纪法意识、知纪守纪。

2、党组织关系从北外滩转移到彭浦镇

为了更好的顺应公司发展及属地化管理需求，上海久之润党支部于2024年6月提出申请，将党组织关系从北外滩转移至静安区彭浦镇。经过相关审批程序，党组织于11月顺利完成整建制转移。此次转移为党支部进一步加强基层组织建设、发挥战斗堡垒作用提供了有力保障。

3、深化党建基础工作及党风廉政建设

在电广传媒党委的指导下，久之润党支部持续推进党建标准化、规范化建设，严格落实《党支部标准化建设实施办法》，扎实开展“三会一课”、主题党日等活动，加强党员思想政治建设。同时支部深入开展党风廉政建设，严格落实中央八项规定精神，通过专题党课、警示教育等活动，筑牢党员干部拒腐防变的思想防线，进一步巩固了清廉务实的政治生态。

二、亮点工作

2024年，久之润党支部以“学史明理、增信崇德”为主题，积极开展系列主题党日活动，取得了显著成效。重温红色记忆，传承革命精神：5月29日，支部全体党员赴上海少年村纪念馆，追寻赵朴初居士的足迹，深切缅怀革命先烈的丰功伟绩。通过参观学习，党员们思想上受到了一次深刻洗礼，更加坚定理想信念，牢记初心使命。赓续红色血脉，担当时代使命：6月26日，支部联合北外滩党建办，参观中国近现代新闻出版博物馆，感受百年新闻出版事业的沧桑巨变。党员们从中汲取了奋进力量，纷纷表示要以更加饱满的热情投入到工作中，为党的事业贡献自己的力量。通过以上主题党日活动，支部党员的政治素养和党性觉悟得到了进一步提升，党员队伍的凝聚力、战斗力显著增强。

三、存在的问题

尽管2024年久之润党支部在党建工作中取得了诸多成效，但仍存在一些不足之处，一是党员教育培训仍缺乏针对性，虽然组织了形式多样的学习活动，但部分党员理论联系实际能力有待提高。二是党支部在发挥战斗堡垒作用方面有待加强，在一些具体工作中，党支部的引领作用不够突出，党员先锋模范作用发挥不够充分。三是党支部在创新工作方法、丰富活动形式方面还需下更大功夫，部分党建活动形式较为单一，党员的参与积极性有待进一步激发。

四、2025年工作计划

2025年，上海久之润党支部在电广传媒党委的领导下，继续以习近平新时代中国特色社会主义思想为指导，深入贯彻学习党的二十大和二十届二中、三中全会精神，聚焦“两个确立”、做到“两个维护”，持续深化党建工作，通过加强理论学习、健全党支部建设、发挥党员先锋模范作用、推进党建与业务深度融合等措施，为久之润健康发展提供坚强政治保障。
