# 述职报告

上海久之润党支部书记抓基层党建工作述职报告

中共上海久之润信息技术有限公司支部委员会书记

文锦子

按照镇党委要求，现将本人2025年度抓基层党建工作情况报告如下：

责任落实情况

2025年，作为支部书记，我认真履行基层党建“第一责任人”职责，紧扣“彭聚力”党建品牌要求，带领支部全体党员凝心聚力，扎实推进各项工作。

一是突出政治引领，抓实理论武装。我始终把党的政治建设摆在首位，严格落实组织生活制度。上半年，我紧扣深入贯彻中央八项规定精神学习教育这一重点，组织开展专题学习，确保党员干部思想“不掉队”、作风“不走偏”。下半年，带头领学《习近平谈治国理政》第五卷，引导党员深入学习党的二十届四中全会精神。同时，积极响应号召，组织全体党员参加全市新兴领域党员“同上一堂党课”，进一步强化了党员的身份意识和政治归属感。

二是夯实组织基础，筑牢战斗堡垒。我着力推进党支部标准化规范化建设，全年主持召开党员大会4次，严格按程序顺利完成支部换届选举工作，由本人继续担任党支部书记，切实保障了工作的连续性。在抓党员队伍建设上，我主动跨前一步，通过细致排摸，成功发掘并接收一名“口袋党员”转入组织关系，消除了管理盲区。同时，扎实做好梯队建设，重点加强对一名预备党员的培养考察，确保党员发展质量。

三是丰富活动载体，激发组织活力。我严格落实“三会一课”等制度，针对小支部特点，灵活开展形式多样的组织生活。在纪念中国人民抗日战争暨世界反法西斯战争胜利80周年之际，组织党员集中观看“九三阅兵”大直播；12月10日组织全体党员赴彭浦镇小镇史馆开展现场教学，沉浸式回顾了彭浦镇的发展变迁。我注重通过常态化的谈心谈话和学习交流，引导党员在平时公司业务中亮明身份、争当表率，发挥党员先锋模范作用。

二、存在问题及原因分析

对照镇党委要求和职工群众期待，认真查摆，主要存在以下问题：

政治理论学习的深度和实效性还不够。虽然能够按要求组织开展学习，但在系统学、深入学上下功夫还不够。有时满足于读文件、看视频等常规动作，对党的创新理论学深悟透做得还不够到位。

（二）党建工作与业务经营的深度融合还需进一步探索。虽然一直强调党建引领，但在实际操作中，将党建优势转化为企业发展优势的载体还不够丰富，党建工作与业务流程的契合度有待进一步增强，双方互促互进的局面尚未完全形成。

（三）作风建设的长效化机制需进一步完善。在抓作风建设方面，落实中央八项规定精神学习教育有时满足于完成规定动作。对于如何将优良作风和廉洁从业理念内化为党员干部的日常自觉，制度设计的严密性和执行的韧劲还需进一步加强。

存在上述问题，主要原因有：

一是创新开展工作的意识不够强。习惯于沿用“读报纸、念文件”的老办法组织学习，对新形势下如何运用新媒体手段提升理论学习效果的研究不深。

二是精力投入失衡。在面对繁重经营压力时，对党建规律的把握还不够透彻。潜意识里对如何实现党建与业务“双轮驱动”缺乏系统性的认识。

三是宗旨意识淡化。在抓作风建设上，有时存在“差不多”心态，缺乏持之以恒、久久为功的韧劲。对党员干部在日常细节上的监督管理不够严格。

三、下一步对策措施

针对上述问题，2026年我将重点做好以下工作：

一是强化政治引领，提升学习质效。我将带头深学笃行党的二十届四中全会精神，一以贯之抓好理论武装。积极探索新媒体等更符合小支部特点的学习载体，力争把理论学得更生动、更扎实，切实筑牢党员干部的思想根基。

二是创新教育载体，提升组织活力。我将不断探索党建融入业务的有效途径，努力找准党建工作服务企业发展的着力点。尝试建立党建与业务双向交流互动的机制，引导党员在各自岗位上进一步发挥先锋模范作用。

三是严抓作风纪律，促进融合发展。持续抓好中央八项规定精神学习教育的贯彻落实，常态化开展纪律教育和警示教育。注重加强对党员日常行为的引导和规范，不断完善作风建设的长效机制，为公司健康发展提供坚强的纪律保障。

上海久之润党支部书记   文锦子
