# 党建工作总结

中共上海久之润信息技术有限公司支部委员会

2025年度党建工作总结及下一年计划

2025年，上海久之润党支部在彭浦镇党委和电广传媒党委的领导下，深入贯彻习近平新时代中国特色社会主义思想，紧扣作风建设主线，推进八项规定精神学习教育，完成换届选举，探索党建与经营融合路径，为公司稳经营、提质效提供了坚强保障。现将全年工作总结如下：

一、2025年度党建工作情况

1、聚焦主线任务，夯实作风建设基础

2025年，支部将贯彻落实中央八项规定精神作为政治建设重点，组织专项学习。年初制定计划，4月24日，支部书记以《作风建设永远在路上》为题讲授专题党课，阐明作风建设重要意义。支部还组织研读《习近平关于加强党的作风建设论述摘编》并开展研讨。7月召开阶段性总结会，梳理成效，持续巩固学习成果。

2、坚持强基固本，提升规范化建设水平

支部持续加强组织建设，严格按照规定顺利完成换届选举，文锦子同志连任书记，为支部工作连续推进提供了组织保障。日常运行中，严格落实“三会一课”，全年召开党员大会4次，组织生活规范有序。党员管理方面，主动排摸并成功接收1名“口袋党员”转入，消除管理盲区；同时加强对1名预备党员的培养考察，优化队伍结构。

3、用好属地资源，增强组织凝聚力

支部依托属地资源，开展务实的主题党日活动12次。1月10日，参加彭浦镇“灵蛇献瑞”活动，增进与兄弟单位交流。5月23日，积极响应上级号召，组织全体党员参加全市新兴领域党员“同上一堂党课”，进一步强化了党员的身份意识和政治归属感。9月3日，组织收看“九三阅兵”直播，共忆峥嵘岁月，激发爱国热情。12月10日，赴小镇史馆现场教学，回顾发展历程，增强党员属地认同。

4、鼓励亮明身份，立足岗位发光发热

支部注重引导党员在日常工作中增强党员意识，通过常态化的教育引导，鼓励全体党员主动亮明身份，立足本职岗位发光发热。支部号召大家从身边小事做起，在日常业务中争当表率，以实际行动践行优良作风，在平凡的岗位上发挥先锋模范作用，带动身边群众共同进步。

二、存在的主要问题

在肯定成绩的同时，支部也清醒认识到工作中仍存在差距和不足：一是理论学习的系统性和深度仍需加强，部分学习停留在规定动作层面；二是党建与业务深度融合的具体载体还不够丰富，实际抓手有待进一步明确；三是作风建设长效机制仍需完善，制度执行的持续性和约束力有待增强。

三、2026年工作思路

2026年“十五五”开局的关键一年，久之润党支部将在电广传媒党委的坚强领导下，坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的二十届四中全会精神，紧紧围绕上级党委年度党建工作要点，牢牢把握“两个确立”、坚决做到“两个维护”，持续强化政治建设和思想引领，推动党建工作与久之润年度目标任务深度融合、同向发力，为久之润高质量发展提供坚强政治保证和组织保障。
