# 理论学习发言

电广传媒、湖南经视

党委理论学习中心组2025年

第五次集体学习会

--上海久之润 顾懿发言稿（2025年7月18日）

尊敬的艳忠书记、各位领导、各位同事：

大家好！非常荣幸能通过视频连线参加电广传媒、湖南经视党委理论学习中心组2025年第五次的集体学习。作为久之润负责人，刚才聆听了艳忠书记对习近平总书记重要文章《锲而不舍落实中央八项规定精神，以优良党风引领社风民风》的领学，我深受教育和启发。我深刻认识到，中央八项规定精神不仅是对党员干部的严格要求，其蕴含的求真务实、勤俭节约、清正廉洁等核心精神，更是指导我们企业穿越周期、实现高质量发展的根本遵循。下面，我结合久之润的实际工作，谈三点学习体会。

第一，以“实”为魂，筑牢企业发展的“压舱石”

习近平总书记强调，“谋事要实、创业要实、做人要实” 。我理解，对企业而言，最大的“实”，就是创造实实在在的经营业绩，履行好国有资产保值增值的责任。过去几年，我们始终坚持“稳中求进”的工作总基调，一方面精细化运营好《劲舞团》等核心产品，守住基本盘；另一方面，在布局直播互动娱乐产品、小游戏等新赛道时，我们坚决反对“赶时髦、追风口”式的盲动，坚持以深度的市场调研和用户数据分析为决策依据。正是这种“求真务实”的作风，让我们有效规避了诸多行业泡沫，确保了久之润战略的稳健落地。这是对总书记“抓铁有痕、踏石留印”精神最直接的实践。

第二，以“严”为尺，为新业态赛道扣紧“风纪扣”

总书记要求要“严以用权、严以律己”，并且“越往后执纪越严”。当前，久之润正大力拓展直播互动娱乐产品、小游戏等新业务，这些领域变化快、模式新，潜在的风险也更大。就在上周，我们关注到B站发布内部通报，其游戏合作部门原总经理因职务犯罪被依法逮捕的案例。这个发生在我们身边的行业案例，为我们重重地敲响了警钟。它警示我们，如果缺乏严格的制度规范，“业务拓展”就极易沦为“风险敞口”。因此，我们必须用“严”的标准，在内容采购、流量投放、对外合作等关键环节，建立起清晰、可执行的内控制度，坚决杜绝“讲排场比阔气”式的资源浪费 ，防止在快速发展中出现任何廉洁风险，这是对“防微杜渐”精神的具体落实。

第三，以“人”为本，打造风清气正的“创业场”

总书记指出，作风建设要“从领导干部做起”，要“把群众的安危冷暖放在心上”。我理解，对企业而言，“群众”就是我们的员工。优良的作风最终要体现在团队的凝聚力和战斗力上。作为负责人，我将带头反对形式主义、官僚主义 ，营造简单、高效、透明的管理氛围。在近期开展的学习教育自查中，我们主动查摆出“对员工因超时工作带来的身心疲惫关注不足”的问题，并已建立台账、立行立改。我们把对群众的关心，具体落实到对员工的每一次关怀上，不断完善激励机制，保障团队稳定。因为我们坚信，一个让大家能心无旁骛去干事创业的环境，才是企业发展的活力之源。

优良的作风，就是企业最核心的竞争力，是我们最宝贵的无形资产。一个求真务实的作风，最终会沉淀为我们的产品品质和用户口碑；一个纪律严明的作风，是我们抵御风险、保障安全发展的坚固“防火墙”；一个以人为本的作风，是我们凝聚人才、激发团队创造力的根本源泉。这正应了总书记所强调的，“作风建设永远在路上”。对久之润而言，这就是需要我们持之以恒、久久为功的永恒课题。

接下来，我将带领久之润全体同仁，继续深入学习领会中央八项规定精神的精髓要义，并将其更全面、更深入地贯彻到久之润的各项工作中，以务实、高效、清正的作风，为电广传媒的高质量发展贡献我们的全部力量！

我的发言完毕，谢谢大家！
