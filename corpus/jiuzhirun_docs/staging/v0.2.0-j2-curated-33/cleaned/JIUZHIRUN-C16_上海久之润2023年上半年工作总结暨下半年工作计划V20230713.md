# 半年度总结

关于上海久之润信息技术有限公司

2023年半年度经营工作总结

暨下半年工作计划

电广传媒总部：

关于上海久之润信息技术有限公司2023年半年度经营工作总结暨下半年工作计划，现报告如下：

一、上半年经营情况

1、2023年上半年经营目标完成情况

2023年度目标为：全年收入4.856亿，归母净利润1.258亿。上半年实现收入2.52亿元，同比增长5.4%，完成年度预算目标52.0%，实现归母净利润7409.2万元，同比下降2.1%，完成年度预算目标58.9%，收入及归母净利润均实现时间过半，完成过半。

单位：万元

2、2023年上半年经营分析

今年虽然版号发放恢复正常，但总体受新冠疫情持续影响，国内外形势严峻复杂，宏观经济仍处于恢复阶段，行业信心不足，给久之润的发展带来挑战。同时新游包括手游《拂晓：胜利之刻》、手游《红月之契》及《郡主别怕》等仍未达预期，由于疫情的解封，相较去年成本费用方面也有一定增长。

针对上述内外部环境不利因素及状况，久之润采取以下措施：

1）久之润首先继续在稳定《劲舞团》老产品方面不断探索、发力，该产品自2023年Q1以来屡次创下近10多年来月初游戏内充值新高，通过不断探索新的方法和策略，项目组成功扭转了去年Q4活跃用户数量下降的趋势，为久之润在全年任务上打下了坚实基础。

2）上半年两款《劲舞团》移动端产品好于预期，其中原计划年中合作到期的《心动劲舞团》H5继续续约并贡献现金流，与网易合作的《劲舞团手游版》更是同比获得较大增长，在新产品手游《一起奔赴的星光》交替前，继续做好版本更新等工作，以维持在收益上的贡献。

3）截止今年5月中旬，潮玩二手交易平台“娃友圈”总体上升势头不错，版本小步、高频更新的打发效果良好，使产品走上了良性循环之道。进入5月下旬以来，增长的势头有所停滞，下半年重点是如何抑制下降趋势，保持现有的GMV和佣金收入规模，不断调整、优化产品功能、提升买卖双方使用体验。

4）成本费用方面，包括工资总额控制等，本年度继续发扬《厉行勤俭节约》的电广精神。由于今年是疫情恢复后的第一年，各项费用也恢复到正常水平，例如差旅费、业务招待费、水电费等缩减已无法再持续，因此在年度预算的参考范围内，尽力做好成本控制，为最终净利润目标实现打好基础。

二、重点工作完成情况

1、深入探索电竞赛事相关业务，制定实施方案，按照总部决策组织实施。

实施进度：上半年国内电竞赛事市场发生了多起重大事件，其中包括腾讯计划发行的多款电竞黑马产品获得版号以及杭州亚运会针对参赛电竞项目直播制定的一系列规范政策，将对国内赛事市场产生重大影响。因此，久之润电竞赛事业务仍处于谨慎观望状态，下半年将根据市场变化进行进一步探索。

2、游戏新产品实现突破，在国内外上线并实现收入的新产品不低于3个。

实施进度：本年度力争在游戏新产品上实现突破，年内预计上线内测产品有3款，具体如下：

1）手游《红月之契》：与海南盛娱联合研发的竖版回合制放置类卡牌手游，广州叶子戏将负责国内发行。版本方面上半年已完成公测版本开发并启动3次国内买量测试，下半年根据发行策略率先开启海外上线运营，国内则根据版号审批时间积极推进国内市场上线。

2）手游《蜡笔小新家庭派对》：由日本双叶社及国内代理商上海艾影授权的社交类IP手游产品，成都谷太萌和深圳奎托斯团队联合研发制作。版本方面目前已完成安卓端公开测试，下半年预计将根据发行计划率先在海外市场上线运营并实现收入。

3）手游《郡主别怕》：上半年完成《郡主别怕》的PC版本开发，并在STEAM平台上以抢鲜体验形式上架进行玩法测试。下半年将根据测试反馈，制定进一步产品发行计划。

3、积极拓展潮玩业务，商品交易总额不低于1亿元。

实施进度：2023年上半年，潮玩二手交易平台“娃友圈”累计实现GMV超5000万元，累计用户15万余人，通过高频更新迭代，持续打造稳定的电商交易平台。然而受到潮玩行业整体大环境趋势下滑影响，当前平台交易规模增速放缓，下半年努力维持趋势稳定，争取年度商品交易总额完成年度目标。

三、上半年工作亮点

端游《劲舞团》自2023年Q1以来屡次创下近10年来月初游戏充值新高；市场活动方面，强势登陆B站跨年夜晚会；5月20日更是迎来18周年庆系列活动上线，用户环比上涨61%，再创历史峰值。今年上半年版号发行回归正常，在行业竞争愈发激烈的背景下，久之润在管理层的带领下，上半年累计实现收入2.52亿元，归母净利润7409.2万元，实现全收入净利任务双过半。

四、痛点难点及对策

1、薪酬体系落后

久之润现有的薪酬标准在上海游戏行业缺乏竞争力，此外上海社保基数不断上涨，相比2022年，23年的上海社保基数涨幅甚至高达12.12%，这导致在久之润现有的薪酬标准体系下，员工的收入难以满足其日益增长的生活成本，进而引发员工流失问题，对与优秀人才更是毫无竞争力和吸引力，这是久之润面临的主要经营困难之一。因此，久之润需要积极调整薪酬体系，提高员工的薪酬福利待遇，以留住现有人员并吸引更多优秀的人才加入企业。

2、私服外挂横行

上半年，端游《劲舞团》的私服问题有所抬头，这给久之润的著作权和商业利益带来了严重的侵害，同时也破坏了市场经济秩序。为了保护自身权益，久之润积极采取措施，加大对私服的监测力度，与公安、网安、经侦等部门建立常态化沟通机制，加强监管和打击力度，维护游戏的公平性和正常秩序。久之润将坚定不移维护自身的知识产权和商业利益，确保游戏的公平性和健康发展，为广大玩家提供更好的游戏体验。

五、下半年计划

项目上，久之润将着重围绕以下几个方面开展工作：

1、《劲舞团》系列尤其是端游产品，在总结上半年经验的前提下，下半年将持续提升品牌度曝光，稳定在线人数、确保产品收入。产品功能迭代上计划不断优化端游《劲舞团》重置版，以提升用户粘性。

2、为实现新产品突破，久之润将加快新产品的研发及上线节奏，结合市场实际制定详细发行计划，力争年底前在国内外上线3款新产品并实现收入。

3、直播互动娱乐产品项目，下半年加强与平台及公会的合作，提高开播量，扩大单场规模，同时努力拓展新产品，争取直播流水千万级别。

4、二手潮玩项目在当前行业大环境趋势下以稳定运营为主，同时配套更新更多平台拉新机制，继续拓展用户群体及商品品类，稳定平台交易规模。

5、努力参与到总部“文旅+投资”战略发展中，积极发挥自身IP内容运营优势，在文旅业务中赢得合作发展业务机会，从而实现久之润在广电体系中的更大价值。

财务上，预计2023年久之润全年营收和归母净利润将与预算目标持平，即收入预计将达4.856亿，归母净利润预计为1.258亿。

单位：万元

从上最近三年和2023年目标的主要经济指标如上可见，近三年收入总体呈增长态势，其中2022年收入增长停滞。净利润前两年呈现增长，而2023年预计将有3.8%左右的小幅下降。

2022年总收入停滞的主要原因是：《机动战士敢达OL》和《红莲之王》两款游戏代理到期停运，而经过一年左右新产品、项目的陆续上线贡献收入，2023年收入预期又将恢复增长。

2023年收入虽预期有所增长，但鉴于其有新产品和项目增量带来的收益并不高，而上线新游和准备中的新游外包研发费用等开支又较大，对利润影响还是比较大的，特别是2023年下半年，还要为下一年新产品的开发外包费用做准备，故下半年利润将会低于上半年。久之润会努力协调，在全年度力争实现收入4.856亿人民币的基础上，确保达成归母净利润1.258亿人民币的年度总目标。
