# 党建工作总结

中共上海久之润信息技术有限公司支部委员会

2023年度党建工作总结及下一年计划

2023年是全面贯彻党的二十大精神的开局之年，也是电广传媒“新文旅、大资管”战略落地的关键之年。上海久之润党支部在电广传媒党委的正确领导下，以习近平新时代中国特色社会主义思想为指导，深刻领会“两个确立”，坚决落实“两个维护”，强化党对国企的领导，在推动全面从严治党向基层延伸中，提升了组织力，为公司的健康发展提供了坚强的政治和组织保障，展现了党建工作对公司发展的重要推动作用。

一、2023年度党建工作情况

1、扎实开展主题教育，提升政治素养

在电广传媒党委的统一领导下，上海久之润党支部扎实开展学习习近平新时代中国特色社会主义主题教育，通过精心部署安排和组织，成功激发了党员们的学习热情，实现了理论学习与实际应用的有效结合。今年，一共开展了4次主题教育读书会，党员们积极交流心得体会，加强了对党的理论的理解和应用。这些活动显著提高了党员们的思想政治素质，展现了久之润党支部在思想建设上的扎实成果。

2、深化“五化”实践，筑牢战斗堡垒

久之润党支部始终致力于加强制度建设，坚持以“三会一课”为核心，不断推进党的理论武装和提升党员素质。在支部书记的领导下，久之润党支部以“五化”建设为核心抓手，全年共开展了12次党员大会和12次主题党日。这些活动有效地提高了党员的政治理论水平，同时促进了党员间的深入交流。并且，我们将意识形态工作作为党建的核心内容，坚定地维护正确的政治方向和舆论导向，不断加强党支部的组织建设和制度完善。

3、深化廉政教育，提升责任担当

在全年中，久之润坚定不移地推进党风廉政建设。总经理顾懿和党支部书记文锦子积极履行“一岗双责”责任，带头学习、带头履职，全年共参与了6期电广传媒的党风党纪教育活动。他们还分别与各部门负责人进行了监督谈话，确保党风廉政建设责任落到实处。此外，久之润多次开展党风廉政专题会议，深入贯彻学习电广传媒总部相关文件精神和重要讲话，为营造清风正气的干事创业环境奠定了一定基础。

二、亮点工作

2023年8月15日，在日本无条件投降78周年之际，上海久之润党支部组织全体党员赴上海淞沪抗战纪念馆开展主题党日活动。党员们通过深入了解淞沪抗战的历史，不仅缅怀了革命先烈的英勇事迹，也在心灵深处重燃了对国家和民族的责任感与使命感。此次活动不仅增强了党支部的凝聚力和战斗力，也激发了全体党员在今后工作中的奋斗热情。

三、存在的问题

尽管2023年上海久之润党支部在党建工作中取得了一些成绩，但我们也存在一些亟需改进的问题。一是，在理论学习方面，我们对于习近平新时代中国特色社会主义思想的学习还显得浅尝辄止，未能达到深入人心的程度。二是，我们的党建活动形式还不够丰富，缺乏创新性和吸引力，这在一定程度上影响了党员的积极性和参与度。三是，个别党员在发挥先锋模范作用方面还存在不足，这在党员日常工作和党内活动中表现得较为明显。

四、2024年工作计划

在2024年，上海久之润党支部将致力于更加深入地开展学习习近平新时代中国特色社会主义思想主题教育，全力以赴深化对党的二十大精神的学习与贯彻。同时，我们将强化意识形态工作，确保党的各项方针政策在久之润的各个层面得到全面实施。通过这些持续的努力，久之润党支部将进一步发挥党建引领作用，凝心聚力，为久之润的持续稳定发展提供更为坚固的政治和组织支持。
