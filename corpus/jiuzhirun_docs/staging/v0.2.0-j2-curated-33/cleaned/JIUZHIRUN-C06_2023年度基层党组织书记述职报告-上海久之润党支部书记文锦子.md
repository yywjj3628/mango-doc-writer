# 述职报告

2023年度基层党组织书记

抓基层党建述职报告

上海久之润党支部书记  文锦子

尊敬的北外滩党工委：

今年是全面贯彻党的二十大精神的开局之年，是三年新冠疫情防控转段后经济恢复发展的一年。作为上海久之润信息技术有限公司党支部书记，回顾2023年的党建工作，我们在湖南电广传媒党委和北外滩街道党工委的指导下，紧紧围绕中心工作，坚持以习近平新时代中国特色社会主义思想为指导，不断深化党的理论学习，全力推进党建工作与企业发展的深度融合。现将过去一年的工作进行总结，并对未来的工作方向提出计划和建议。

一、2023年支部书记履职情况

1、坚定理论武装，深入学习贯彻习近平新时代中国特色社会主义思想

在2023年，我们党支部高度重视理论学习，持续开展学习习近平新时代中国特色社会主义思想主题教育，以引导广大党员干部坚定拥护“两个确立”，坚决做到“两个维护”。久之润党支部全年共组织了4场《习近平新时代中国特色社会主义思想专题摘编》读书会，全体党员得以深化对党的最新理论成果的理解和认识，会后党员们彼此交流读书心得。此外，鼓励党员们积极利用学习强国APP，随时随地了解党的方针政策和理论动态。

2、强化支部建设，筑牢基层战斗堡垒

上海久之润党支部在北外滩街道党工委指导下，积极推进基层组织建设，以党建引领互联网游戏企业健康发展。重点强化严格落实组织生活，“三会一课”等制度，全年举办了12次党课、12次主题教育活动以及支部书记上党课活动，通过形式多样的组织生活活动，有效提升党员参与度。在党费管理上，严格遵循相关规定，实现党费管理的严谨和透明。同时，积极参与街道党工委组织的各类党建活动，如主题教育活动、二十大学习系列活动，提高党员理论知识和党建业务素养。

3、通过活动的开展有效提升党员政治素养

为提升党员政治素养，上海久之润党支部在2023年8月15日，即日本无条件投降78周年之际，组织全体党员前往上海淞沪抗战纪念馆参观学习。这次活动不仅是对淞沪会战的历史回顾，也是加强党员政治意识的重要环节。通过观看历史文物和听取讲解，党员们深刻感受到了抗战先烈的英勇无畏和伟大牺牲，增强了作为党员的历史责任感和使命感。此次活动成为我们一系列政治教育活动中的亮点，有效地提升了党员的政治素养和综合能力，进一步坚定了他们在新时代积极履行党员职责的决心。

二、存在问题及原因分析

（一）组织活动参与度不高。我们的党支部虽然积极策划并执行了多项组织活动，旨在增强党员间的交流与学习，但实际上发现部分党员对这些活动的参与热情并不高。这导致了活动的实际影响力和覆盖面远未达到预期，影响了活动的整体效果和党组织的凝聚力。

（二）党员教育培训效果一般。我们定期开展党员教育和业务培训，以提高党员的理论知识和业务能力。然而，反馈显示，这些培训的效果并不理想。虽然定期组织，但培训内容和方法可能过于陈旧，缺乏创新和实际操作，使得培训的吸引力和实用性有限，未能充分提升党员的理论和实践水平。

（三）基层党组织与企业发展融合度不足。尽管党组织在企业中扮演着重要角色，但在日常运营中，党组织的工作与企业的具体运营之间存在一定的脱节。党组织的活动和决策未能与企业的发展战略和日常管理紧密结合，未能发挥最大的引领和服务作用，影响了党组织在企业发展中的核心作用。

主要原因分析：

一是活动安排与党员实际需求未完全契合。在组织活动时，未能充分考虑到党员的实际工作和生活情况，导致活动设计与党员需求存在偏差，使得部分活动的吸引力和参与度不足。

二是教育培训内容与形式较为传统。当前的教育培训依然主要采用传统的授课方式，缺乏必要的创新和互动性，导致培训内容枯燥，难以吸引党员的兴趣和参与，影响了培训的有效性。

三是党组织工作与企业运营脱节。虽然在理论上党组织在企业中具有重要地位，但在实际工作中，党组织的作用未能与企业的具体运营紧密结合。需要探索更有效的方法，以确保党组织的工作能更好地服务于企业的发展目标，实现党组织与企业发展的深度融合。

三、下一步工作思路及主要措施

（一）提高组织活动的针对性和吸引力。针对当前活动参与度不高的问题，我们计划深入调研党员的需求和兴趣，设计更加贴近党员实际的活动内容。计划引入更多形式多样、内容丰富的活动，如线上研讨会、主题实践活动等，增加互动性和趣味性。同时，将积极探索灵活多变的活动时间安排，以便更多党员能够参与。通过这些措施，我们期望能显著提升党员的参与度和组织活动的实际效果，增强党组织的凝聚力和影响力。

（二）创新党员教育培训模式。面对教育培训效果一般的问题，我们计划改革现有的培训模式，引入更加多样和互动的培训方式。例如，开展在线培训课程，利用互联网平台进行互动式学习，引入案例分析和角色扮演等方法，以提高培训的趣味性和实效性。同时，将定期组织党员进行交流和分享，鼓励党员之间相互学习，共同进步。通过这些举措，我们希望能够有效提升党员的理论水平和业务能力，增强党组织的整体素质。

（三）加强党组织与企业发展的融合。为解决党组织工作与企业运营脱节的问题，我们将积极探索和实施党建工作与企业管理的深度融合策略。计划通过设立党建项目小组，将党建工作与企业的具体业务结合起来，如在产品开发、市场推广等方面引入党建元素。同时，将定期组织党员参与企业的决策讨论，确保党组织的意见和建议能够及时反映在企业的日常管理和长远规划中。通过这些措施，我们旨在提高党组织在企业发展中的实际作用，实现党建工作与企业发展的共赢。
