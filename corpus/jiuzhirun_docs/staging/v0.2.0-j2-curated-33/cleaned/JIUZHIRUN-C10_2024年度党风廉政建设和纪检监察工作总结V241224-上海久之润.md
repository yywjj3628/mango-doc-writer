# 纪检工作总结

2024年度党风廉政建设和纪检监察工作总结

2024年是深入学习贯彻党的二十大精神和习近平新时代中国特色社会主义思想的关键之年。在电广传媒党委的坚强领导和纪委的具体指导下，上海久之润以开展党风党纪和廉洁从业教育活动为契机，严格贯彻落实全面从严治党的战略部署，坚持推进党风廉政建设和反腐败斗争，扎实开展各项纪检监察工作，为营造久之润风清气正的工作环境提供了坚强保障。现将全年工作总结如下：

一、党风廉政建设落实情况

1、提高政治站位，强化政治监督

久之润始终以习近平新时代中国特色社会主义思想为指导，深入学习贯彻习近平总书记考察湖南重要讲话精神。通过管理层专题会议、党支部“三会一课”以及主题教育等形式，强化理论学习与实际工作深度融合，确保党的决策部署在久之润落地生根。此外，久之润总经理顾懿也积极参与电广传媒党风党纪和廉洁从业教育活动，高度重视理论学习，并身体力行带头学习。

2、加强党纪教育，营造廉洁氛围

久之润积极配合总部纪委要求，扎实推进廉洁文化建设。组织党员领导干部深入学习电广传媒领导关于党风廉政建设和反腐倡廉的讲话和文件，积极转发“党风党纪每日一课”微信帖子，引导全体党员干部学纪、知纪、守纪。特别是在中秋、国庆等重要节点，久之润通过发送廉政提醒邮件、张贴宣传标语等形式，持续营造风清气正的政治生态。

3、推进专项整治，深化问题整改

根据总部纪委工作部署，久之润严格贯彻执行“靠企吃企问题专项整治‘四个一’系列活动”，深入排查各类廉政风险点，并对总部下发的454家“交易禁入名单”逐一排查，积极与总部沟通，拟将深圳奎托斯和成都古太萌两家单位剔除名单，从而为久之润的业务发展创造更有利条件，相关申请报告已递交至总部。

4、驰而不息纠治“四风”，营造风清气正环境

久之润严格贯彻落实中央八项规定精神，坚持问题导向，聚焦形式主义、官僚主义等顽瘴痼疾，持续深化作风建设。通过秉承厉行节约、艰苦奋斗的优良作风，同时不断强化监督检查，确保问题防范于未然。2024年未发现“四风”问题线索，清廉、务实的作风建设成果进一步巩固。

二、纪检监察工作落实情况

1、全面落实总部要求，强化监督检查

在总部纪委的指导下，久之润纪检监察工作稳步推进。全年累计开展内部检查2次，重点聚焦三公经费、合同审批及项目结算环节，确保关键岗位和重要环节监督无死角。结合电广传媒廉洁从业教育会议精神，针对廉政风险较大的业务部门开展专项自查，切实压实监督责任，提升内控效果。

2、巩固纪律作风建设，推进“清廉电广”落地

久之润积极推进做好“清廉电广”建设，通过廉政教育培训、警示案例学习和反腐倡廉座谈等形式，不断提高党员干部的廉洁意识和规矩意识。同时组织纪检干部积极参与总部纪委的在线答题活动，进一步夯实了廉洁从业基础。

三、问题与改进措施

2024年，久之润党风廉政建设和纪检监察工作虽取得一定成效，但仍存在不足。一是思想认识有待提升，部分员工对党风廉政建设重要性认识不足，廉洁自律的主动性仍需加强。二是教育形式单一，集中学习和文件传达为主，缺乏互动性和吸引力。三是监督管理精细化不足，部分业务环节监督覆盖率不够，尤其是外部合作项目的过程监督亟需加强。

针对上述问题，拟采取以下改进措施：一是强化思想引导，通过案例研讨、主题党课等创新形式，加强廉洁文化教育，提升全员纪律意识。二是创新教育形式，运用警示教育视频和“清风芒果”等线上资源，增强教育吸引力和实效性。三是提高监督覆盖率，强化关键岗位和重点环节的过程监督，确保问题早发现、早整改。

四、未来工作计划

1、持续推进党风廉政建设和纪律教育

久之润将继续深入学习贯彻党的二十大精神，结合习近平总书记关于全面从严治党的重要讲话精神，扎实开展党风廉政教育活动，特别是针对新员工和关键岗位人员，加大培训频次和力度，确保廉洁意识覆盖到每一个环节。

2、强化监督管理，巩固廉政防线

计划优化内部监督体系，通过完善和落实群众信访制度以及风险预警机制，提高监督工作的系统性和精准性。与此同时，持续加强对外包业务和合作项目的监督，防范廉政风险，确保久之润运营的透明度和合规性。

3、推动廉洁文化建设走深走实

通过线上线下结合的方式，大力推广“清廉电广”的理念。通过组织警示教育专题讲座、廉政知识竞赛等活动，让廉洁文化内化于心、外化于行，进一步加深久之润全员对廉洁从业的认同和践行。

2025年，上海久之润将一如既往坚守初心、勇担使命，进一步强化党风廉政建设和纪检监察工作，为久之润健康、持续发展提供坚强政治保障，创造风清气正、干事创业的良好环境。
