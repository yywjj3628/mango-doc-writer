# 纪检工作总结

2023年度党风廉政建设和纪检监察工作总结

2023年是深入学习贯彻党的二十大精神的关键时期，上海久之润在湖南电广传媒党委的坚强领导和纪委的关心下，以开展学习习近平新时代中国特色社会主义思想主题教育为契机，全面加强党的政治建设和纪检监察工作。我们组织党员干部深入学习党的理论，不断提高政治站位，以实际行动推动党风廉政建设和反腐败斗争。同时，我们也意识到在新形势下，我们的工作需要不断加强和改进，以确保久之润在新的一年中实现更加健康、可持续的发展。

一、党风廉政建设落实情况

1、提升政治意识，深入开展理论学习教育

在电广传媒党委的统一部署下，上海久之润深入开展学习习近平新时代中国特色社会主义思想主题教育，我们组织全体党员干部开展了一系列主题教育活动，旨在学深悟透习近平新时代中国特色社会主义思想，通过形式各样的活动，引导每位党员干部都能深刻理解和贯彻党的精神。此外，上海久之润总经理顾懿也积极带头进行理论学习，全年共参与了6期电广传媒党风党纪和廉洁从业教育活动，高度重视党的理论学习。

2. 提升党员意识和执行力，推进党风廉政建设

久之润注重提升党员意识和执行力，强化党支部基础工作，严格落实“三会一课”制度，特别是支部书记讲党课等活动，将理论教育和实际工作结合，增强党员对党风廉政建设的认识。同时，结合电广传媒党风党纪和廉洁从业教育会议，深入学习电广传媒领导关于党风廉政建设和反腐倡廉的讲话和文件，开展廉政警示教育，引导党员干部知“红线”守“底线”。

3、贯彻“一岗双责”，推动党风廉政建设和反腐工作

上海久之润坚定不移地推进党风廉政建设和反腐败工作。总经理顾懿积极履行“一岗双责”，加强对下属领导的监督谈话，确保党风廉政建设的责任落到实处。同时针对电广传媒总部下发的重要会议精神，上海久之润多次开展党风廉政专题会议，加强了相关文件精神和重要讲话的学习和贯彻。通过这些措施，我们确保了党的纪律和规矩在公司内部得到严格遵守，为防止和打击腐败行为提供了坚实基础。

驰而不息纠治“四风”

上海久之润坚定不移地贯彻中央八项规定精神，驰而不息地纠治“四风”，以实际行动反对形式主义、官僚主义。我们秉承厉行节约、艰苦奋斗的作风，坚决狠刹享乐奢靡之风，营造了清廉、务实的工作环境。公司持续深化巡视整改工作，确保整改措施落实到位，防止“前紧后松”的现象。

二、纪检监察工作落实情况

1、传达贯彻总部工作要求，确保各项任务落地见效

在监督检查与整改方面，我们保持了惩治腐败的高压态势。在电广传媒总部纪委统一安排下，上海久之润开展了多项专项核查和检查，重点关注广电系外租外包业务。此外，我们通过查办案件和专项监督，推动了“靠企吃企问题专项整治自查自纠”和“领导干部利用职权或影响力为亲友牟利问题”的整改工作。这些措施有效提高了久之润在党风廉政建设和反腐败斗争方面的管理和监督能力，为营造清廉、健康的企业环境提供了有力保障。

2. 营造廉政文化氛围，提高廉洁自律能力

为了营造良好的廉政文化氛围，上海久之润积极推广电广传媒廉洁自律的价值观和行为规范。我们通过发放节日廉政提醒，教育和提醒员工在节假日期间维持高度的廉洁自律意识。同时，我们也鼓励员工积极关注“清风芒果”公众号，通过这个平台传播廉洁电广的声音，增强员工的廉政意识。这些措施大大增强了公司内部的廉洁自律氛围，提升了全体员工对于廉洁自律的认识和执行力。

三、问题与改进措施

在2023年的党风廉政建设和纪检监察工作中，上海久之润虽取得了一定成就，但也面临着一些挑战和问题。

主要问题：

1、思想认识有待加强：部分员工对党风廉政建设的重要性认识不够深刻，特别是新员工对党纪党规的理解和遵守程度有待提高。

2、党纪教育形式单一：现有的党纪教育方式相对单调，缺乏针对性和吸引力，导致教育效果不理想。

3、日常监督工作细致性不足：在日常监督管理中，对细节的关注和处理不够深入，需要提高监督的覆盖面和针对性。

改进方案和策略：

1、强化理论教育和实践结合：通过定期组织多样化的党纪教育和实践活动，增强员工对党风廉政建设重要性的认识，尤其是加强对新员工的党纪教育。

2、创新教育方式：采用更多互动式教学方法，如案例研讨、警示教育学习等，以提高教育的吸引力和实效性。

3、加强日常监督和精细化管理：提升监督检查的频率和针对性，尤其是对关键岗位和重点领域进行深入监督，确保问题及时发现和纠正。

四、未来工作计划

1、加强理论学习和实践应用

在2024年，我们将继续加强习近平新时代中国特色社会主义思想的学习。特别是将习近平总书记在二十届中央纪委三次全会上的重要讲话精神贯彻到日常工作中。通过组织系列学习活动，确保党的最新理论成果深入人心，增强全体员工的政治认识和行动自觉。

2、创新廉政教育和文化建设

未来一年，我们将创新廉政教育方式，结合线上线下资源，采用更互动性和实践性的教学方法，如案例研讨、警示教育等，提高教育的吸引力和实效性。同时，加大廉洁文化的宣传力度，通过多渠道传播廉洁自律的价值观，进一步营造良好的企业廉政文化氛围，推动久之润党风廉政建设向更深层次发展。
