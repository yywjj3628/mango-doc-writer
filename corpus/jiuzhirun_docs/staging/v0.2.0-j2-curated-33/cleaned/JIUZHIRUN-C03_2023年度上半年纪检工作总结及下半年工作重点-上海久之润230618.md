# 纪检工作总结

2023年度上半年纪检监察工作总结及下半年工作重点

2023年上半年，上海久之润在湖南电广传媒党委的坚强领导和纪委的关心指导下，紧密围绕党的二十大精神和习近平新时代中国特色社会主义思想，全面加强党的政治建设和纪检监察工作。我们组织党员干部深入学习党的理论，提高政治站位，积极推动党风廉政建设和反腐败斗争，确保久之润在新的一年中实现更加健康、可持续的发展。现将上半年的工作总结和下半年的工作重点汇报如下：

一、2023年上半年工作总结

1、深化学习教育，落实“一岗双责”

我们认真学习了《2023纪检监察工作要点》，组织中层干部及党员深入学习二十大精神，强化了“一岗双责”职能，确保党风廉政建设责任制的有效落实。

2、强化廉洁自律，提升拒腐防变能力

通过开展党史学习教育，巩固主题教育成果，我们加强了廉洁警示教育，引导党员干部严守政治纪律和政治规矩，增强了拒腐防变的能力。

3、加强权力监督，防控廉洁风险

重点关注关键领域和环节的廉洁风险，结合行业特点，梳理风险点，完善防控措施，确保权力运行在制度的笼子里。

4、加强作风建设，营造风清气正的工作环境

在重要节假日前发出廉政提醒，严格落实中央八项规定精神，加大对“四风”问题的监督检查力度，确保干部队伍保持良好的政治生态和工作作风。

二、存在问题

1、制度贯彻不够深入：党风廉政建设制度的实施尚需加强，从源头上预防和治理腐败的工作需要进一步深化。

2、纪检干部队伍建设需加强：纪检干部的理论素养和业务能力需进一步提升，以适应新时代纪检监察工作的要求。

三、下半年工作重点

1、进一步推进全面从严治党：深入学习贯彻党的二十大精神，不断提高政治站位，加强理论武装，确保全体党员干部坚定不移跟党走。

2、持续深化廉洁教育：定期组织党风廉政教育活动，增强党员干部的廉洁自律意识，通过形式多样的活动增强教育的实效性。

3、加强日常监督和专项检查：持续加强对关键领域和重要环节的监督检查，确保“四风”问题得到有效整治，营造风清气正的政治生态。

4、加大队伍建设力度：对纪检干部队伍进行系统培训，提高其理论水平和业务能力，确保纪检监察工作适应新形势的要求。

总之，上海久之润将继续以党的二十大精神为指导，坚持以习近平新时代中国特色社会主义思想为统领，全面加强党的政治建设和纪检监察工作，为公司的可持续发展提供坚实的政治保障和纪律保证。
