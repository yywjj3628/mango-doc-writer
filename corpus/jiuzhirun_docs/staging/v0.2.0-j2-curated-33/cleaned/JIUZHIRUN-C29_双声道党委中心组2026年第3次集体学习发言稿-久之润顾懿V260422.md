# 理论学习发言

电广传媒 湖南经视

双声道党委理论学习中心组

2026年第3次集体学习

--上海久之润 顾懿发言稿（2026年4月23日）

尊敬的艳忠书记、各位领导、各位同事：

按照本次理论学习安排，围绕习近平总书记关于树立和践行正确政绩观的重要论述，我在反复学习“务实功、出实招、求实效”“追求实实在在、没有水分的增长”等要求后，结合游戏行业发展态势和久之润经营实际，有三点体会。

总书记强调，政绩观问题是一个根本性问题，既关系发展方向，也关系发展质量。对企业经营者而言，我的理解是：必须把正确政绩观落实到具体经营行为中，体现为稳住基本盘、把好创新节奏、守住合规底线，坚决防止短期化、表面化和数字化倾向。

第一，以“稳”为基，守住穿越周期的“压舱石”。

总书记指出，要“有战略眼光，看得远、想得深”，同时警惕“心浮气躁、急功近利”。这一要求，本质上是强调发展必须立足长期、经得起周期检验。当前游戏行业供给持续增加、竞争加剧，一些企业为追求短期流水，过度依赖高强度投放，透支用户生命周期换取当月报表。从根本上看，这类做法是以短期波动替代长期能力，难以持续。

今年以来，部分头部企业已出现明显调整，如Epic Games裁员超1000人、育碧关闭多个工作室，预计裁撤近2500人，反映出单一依赖爆款驱动的发展模式正在承压。这也从侧面印证，总书记强调的“善始善终，善作善成”，关键在于坚持长期主义。

基于此，久之润始终把稳定经营作为基础。《劲舞团》已运营二十一年，今年4月份完成T3续约版权金的全部支付，并稳步推进21周年庆筹备。此类产品虽不追求短期爆发，但能够提供持续现金流和稳定用户基础，是久之润穿越周期的关键支撑。

第二，以“慎”为度，把牢创新探索的“方向盘”。

总书记指出，“高质量发展是全面建设社会主义现代化国家的首要任务”，同时强调要防止“盲目蛮干”。这要求我们在推动创新时，既要主动作为，也要坚持从实际出发。

当前，AI技术正加速向游戏行业渗透，GDC大会AI议题占比超过14%，头部企业也在加大布局。从趋势看，技术应用已成为行业共识；但从实践看，不同企业之间能力差异明显。本质上，创新能否形成有效产出，取决于是否与自身能力相匹配。

基于这一判断，我们坚持“跟上趋势、但不盲目抢跑”：一方面推进全员AI工具应用，在策划与内容生产环节提升效率；另一方面控制投入节奏，不进行超出能力边界的激进布局，避免形成新的资源错配。

第三，以“严”为尺，筑牢合规经营的“防火墙”。

总书记强调，要“创造经得起实践、人民、历史检验的实绩”。这一要求不仅体现在发展成果上，更体现在发展过程的规范性和约束性上。

今年以来，行业内多起案例表明，合规风险正由“隐性问题”转为“显性约束”。如米哈游通报4名员工因受贿罪被判刑，24家供应商被永久拉黑；完美世界3名美术骨干因涉嫌与供应商内外勾结被刑拘等。均反映出在业务拓展过程中，一旦制度约束不到位，极易演变为系统性风险。未成年人保护同样是刚性约束。今年3月八部门出台新规，防沉迷落实不到位最高罚款500万元，监管边界进一步收紧。这表明，合规要求已经从“底线约束”转变为“前置条件”。

基于此，我们在经营中始终把合规作为前提而非补充：一方面严格落实防沉迷要求，在充值限制、时长管理等方面不打折扣；另一方面推进合同事中管理系统建设，引入AI Agent辅助审查，从机制和技术两个层面提升风险防控能力。

总体来说，正确政绩观在企业层面的落实，关键在于把发展质量与风险约束统一起来，推动形成稳健、可持续的发展路径。

下一步，我将结合本次学习要求，把相关认识落实到具体经营工作中，持续提升发展质量和规范水平，确保各项工作经得起实践检验，为电广传媒高质量发展作出应有贡献。

我的发言完毕，谢谢大家。
