# 理论学习发言

电广传媒党委理论学习中心组（扩大）

2023 年第九次集中学习研讨会

--上海久之润 顾懿发言稿（2023年11月3日）

尊敬的龚台、王董事长、各位领导、各位同事：

大家好！今天非常荣幸能够在本次电广传媒党委理论学习中心组（扩大）集中学习研讨会上做交流发言。本次会议旨在深入学习贯彻习近平文化思想，以更好地担负起新的文化使命，推进公司高质量发展。会前我认真深入地自学了习近平总书记近期对宣传思想文化工作做出的重要指示和全国宣传思想文化工作会议精神，下面我将结合自身游戏行业的实际情况，浅谈我的一些学习感悟。

早在2014年全国文艺工作座谈会上，习近平总书记就曾明确指出，实现中华民族伟大复兴需要中华文化繁荣兴盛。文化代代传承，思想与时俱进。2023年10月，全国宣传思想文化工作会议召开，正式提出并系统阐述习近平文化思想。习近平总书记对宣传思想文化工作作出重要指示，提出“七个着力”的重大要求。其中“着力赓续中华文脉、推动中华优秀传统文化创造性转化和创新性发展；着力推动文化事业和文化产业繁荣发展”两个要求为今后一个时期的宣传思想文化工作指明了前进方向、提供了科学指南。

游戏作为第九艺术形式，一直扮演着新技术和新产业的试验田和孵化器的角色。它的独特之处在于能够融合多种艺术形式，将音乐、绘画、文学、电影等元素完美地结合在一起，具有着独特的魅力和无限的可能性。作为游戏行业的从业者，通过游戏，我们有机会将中华优秀传统文化与创新的科技手段相结合，是实践中华优秀传统文化创造性转化与创新性发展的重要途径之一。

此外，游戏产品的受众相对来说比较年轻。年轻一代是国家文化传承的中坚力量，他们身上流淌的，是我们民族世世代代不变的文化自觉的基因、家国情怀的血脉。我们应该充分认识到，通过游戏这一媒介，我们可以更好地传递中华文化的精髓和价值观念，激发年轻人对优秀传统文化的兴趣和热爱。

近期市场上已经出现了许多符合传承中华文脉的创新产品。例如，网络短剧《逃出大英博物馆》，由2个自媒体博主自编自导自演，上线5天抖音破2.5亿播放量，获赞近2000万，超过100多万人评论，就连央视网、新华日报等官媒都纷纷点评表扬。该剧讲述了大英博物馆内一盏“中华缠枝纹薄胎玉壶”化为人形出逃，在一名中国记者李永安的帮助下重回祖国的故事，该剧不盲目追逐流量热点，而是运用精细化的制作和深刻的民族文化内涵赢得观众发自内心的掌声，唤起了当下中国年轻人对历史和传统文化的热情，对文化保护传承的重视。

再比如敦煌研究院与腾讯公司联合打造的全球首个基于区块链的数字文化遗产开放共享平台“数字敦煌•开放素材库”，它汇聚了莫高窟等石窟遗址及敦煌藏经洞文献6500余份高清数字资源档案通过素材库向全球开放。“数字敦煌•开放素材库”通过虚拟现实技术与中华优秀传统文化的创新结合，创新性地实现了文化资源共享的又一次数字化升级，也为积极贯彻落实习近平文化思想树立了很好的榜样。

作为文化产业从业者，我们要深刻领会习近平文化思想中茹古涵今和守正创新的理论光辉。切实增强坚决做到“两个维护”的政治自觉、思想自觉、行动自觉，特别是在游戏行业，我们应充分利用新技术和新方向，不断探索创新，将中华优秀传统文化元素与游戏设计相融合，创造出更多具有文化内涵的游戏作品，这不仅有助于传承和弘扬中华文化，为文化事业和文化产业繁荣发展贡献一份绵薄之力，还可以为自身带来新的机遇和竞争力。除此之外，我们还应注重塑造正能量、传递正确价值观的游戏内容，引导年轻人积极向上的精神追求。

上海久之润作为一家国有游戏企业，我们肩负着重大的责任和使命。我们不能只盯着追求经济效益，更要注重传承和弘扬中华优秀传统文化。作为上海久之润的负责人，我充分认识到自身的使命和责任，努力将学习成果转化为行动，用实际行动践行习近平文化思想。只有通过我们共同努力，才能更好地担负起我们肩上的文化使命，为电广传媒的高质量发展做出积极贡献。

谢谢大家！
