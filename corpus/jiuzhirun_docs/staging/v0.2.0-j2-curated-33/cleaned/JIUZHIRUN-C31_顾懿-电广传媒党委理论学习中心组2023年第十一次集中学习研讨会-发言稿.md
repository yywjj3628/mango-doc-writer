# 理论学习发言

电广传媒党委理论学习中心组（扩大）

2023年第十一次集中学习会议上的发言

上海久之润公司总经理  顾懿

（2023年12月20日）

尊敬的龚台、王董事长、各位领导、各位同事：

大家好！今天非常荣幸能够通过视频连线的方式参加本次电广传媒党委理论学习中心组（扩大）2023年第十一次集中学习研讨会，感谢龚台刚才对习近平总书记在中央经济工作会议上的重要讲话精神的传达，在此我将结合自己的学习心得和工作实际，就如何学习贯彻好中央经济工作会议精神，推进公司高质量发展做个简单分享交流。

12月11日至12日，中央经济工作会议在北京举行，习近平在重要讲话中全面总结2023年经济工作，深刻分析当前经济形势，系统部署2024年经济工作。会议明确指出，做好明年经济工作，要以习近平新时代中国特色社会主义思想为指导，全面贯彻落实党的二十大和二十届二中全会精神，坚持稳中求进工作总基调，加快构建新发展格局，着力推动高质量发展。会议对2024年要扎实做好的九项重点任务作出部署，其中让我印象深刻的是以科技创新引领现代化产业体系建设、防范化解重点领域风险及切实保障和改善民生，这对我们规划未来的工作，提升久之润整体质量起到了极为关键的指导作用。

上海久之润已深耕中国互联网游戏行业20余年，我想结合自己长期一线工作经验，分享以下四点心得感悟：

首先，我深刻认识到科技创新对于现代化产业体系建设的重要性。去年11月底，OpenAI发布了一款基于大型语言模型的智能对话机器人ChatGPT，引领了人工智能领域的一场创新革命。作为一家互联网游戏企业，我们要积极拥抱科技发展，不断提升自身的创新能力，通过持续跟进科技浪潮，从而更好地适应行业变革，为玩家提供更具竞争力的产品和服务。就在上周，我们的AI智能客服正式上线，这是我们团队经过几个月的努力研发的成果，也是我们响应科技创新的具体实践。AI智能客服借助人工智能、大数据、云计算等先进技术，为客户提供高效、智能、个性化的服务。通过智能客服的引入，我们实现了人力成本的有效节约，服务效率的显著提升，从而增强了久之润在竞争激烈市场中的竞争力。

会议中明确提出要大力发展数字经济。在此我简要分享下我的认识。数据，作为数字经济的关键要素，构成了数字经济的基石，而数据资产则是数字经济的核心竞争力。数据资源“入表”，就是把数据资源作为资产列入财务报表，反映数据资源的价值和贡献。明年起，《企业数据资源相关会计处理暂行规定》将施行，明确了数据资源的确认范围和会计处理准则等。数据资源“入表”，有助于展现企业的数字优势，为企业依靠数据资源开展投融资等业务提供依据，为企业的可持续发展创造条件。因此，我们要积极响应国家发展数字经济的决策部署，按照财政部发布的《暂行规定》，对数据资源进行合理的会计确认、计量和报告，完善数据资源的列示和披露要求，提高数据资源的管理水平和利用效率，实现数据资源的资产化和价值化。

面对复杂多变的形势，我们更坚持“稳中求进”。久之润始终将自身定位于电广传媒利润主要贡献者，将企业的平稳运行置于首要位置。在这个过程中，我们深刻认识到及时应对市场变化的重要性，加强在关键领域的风险防范，确保久之润整体运营平稳有序。为此，我们采取了一系列切实有效的管理措施，包括内部人员结构的优化、组织架构的调整以及主动裁员等，以达到“降本增效”目的，从而确保久之润能够完成电广传媒下达的经营目标。这也是我们对“先立后破”的具体贯彻，为久之润可持续发展提供了有力支持。

最后，会议还强调了“以颠覆性技术和前沿技术催生新产业、新模式、新动能，发展新质生产力”的重要性。我深受启发，将时刻保持对市场上新技术的关注度，尤其是AR/VR/数字人/直播技术等。我将主动了解这些新技术的商业化进程，它们不仅涉及技术创新和应用，也关乎市场需求和用户体验。通过不断地学习和实践，适时地将它们融入久之润业务布局中，为久之润的长期健康发展注入新的动力。

总而言之，久之润要以本次中央经济工作会议确定的“稳中求进、以进促稳、先立后破”总基调为根本遵循，按照电广传媒党委的统一部署，认真谋划好2024年的工作。要不断加强科技创新能力，做好风险防范工作，保障员工基本利益，确保久之润长期健康稳定的发展，为电广传媒的高质量发展贡献一份力量。

谢谢大家！
