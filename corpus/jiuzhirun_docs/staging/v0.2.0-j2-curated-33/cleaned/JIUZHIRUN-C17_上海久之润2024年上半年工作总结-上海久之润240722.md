# 半年度总结

关于上海久之润信息技术有限公司

2025年上半年工作总结

电广传媒总部：

关于上海久之润信息技术有限公司2024年上半年工作总结，现报告如下：

一、上半年工作总结

（一）2024年上半年经营目标完成情况

2024年度的目标为：全年收入4.752亿，净利润1.355亿。上半年实现收入2.362亿元，同比下降6.4%，完成年度预算目标49.7%，实现净利润6,728万元，同比下降9.5%，完成年度预算目标49.6%，收入及净利润均基本实现时间过半，完成接近过半。由于同比收入及净利润因海外广告代理业务净额法调整，财政补贴收入的延迟等因素有一定下降。

单位：万元

（二）2024年上半年经营分析

今年游戏及各相关平台政策监管持持续趋严、版号高频次的发放导致市场竞争愈发激烈，随着人工智能技术推动游戏行业变革，玩家对沉浸式和高品质游戏体验的期待不断提升。尽管市场环境异常艰难，久之润仍然凭借《劲舞团》系列中《劲舞团》端游组同比持平略增的表现，继续保持住了公司的业绩基盘。然而，去年的亮点业务——娃友圈-福袋业务和海外广告代理，今年因平台等政策原因同比都有明显下降。《劲舞团》移动版因产品生命周期和平台合约到期因素，同比也有所下降。其他次新和新游戏，包括《拂晓》、《红月》、《东方H5》和《蜡笔小新》等，同比下降或未达预期，部分游戏上线延期。在新增量的弹幕游戏方面，B部负责的各小游戏未达预期，而C部负责的《劲舞之星》则达到并超出预期，为公司业绩做出了积极贡献。

在成本费用方面，同比有所下降，主要由于营业成本中《劲舞团》手游的分成费下降，以及销售费用中海外广告代理业务的净额法调整等因素所致。然而，在其他收益方面，由于今年起增值税进项税可加计抵扣政策的取消以及地方财政补贴（退税）的延迟，使得同比大幅下降。最终，利润水平较上年同期下降了约9%，完成全年利润目标接近50%。

针对上述内外部环境不利因素及状况，久之润采取以下措施：

1、首先继续在稳定《劲舞团》老产品方面继续探索、发力，该产品在2023年H1创下近10多年来的新高的基础上，本年2024年H1同比继续得到维持，这也是近十多年来该项目组不断努力进取的结果，期望在本年下半年在加强各项活动的基础上继续取得良好成绩。

2、弹幕游戏《劲舞之星》，是今年来的一个亮点，短平快、入少、见效快，短期内获得了盈亏平衡并开始贡献利润，团队继续小步快走不断摸索、调整新的功能、活动，以期在保持目前水平的基础上更上一层楼。

3、对上半年业绩未达预期的新项目，包括延迟上线的新项目，下半年继续加紧调整，力争在年内为久之润业绩做出一份贡献。同时，我们也在围绕《劲舞团》布局全新的项目，为增量业绩提前做好准备。

4、在成本费用方面，今年一般管理费用同比有所增长，主要原因有两个：一是上年第一季度疫情后期业务非正常开展的不可比因素，二是上年2月后逐步切换至中智外服聘用人员的费用逐渐增加的不可比性。此外，上半年对新项目研发（外包）的投入高于上年，导致总体成本费用压力较大。不过，我们将以利润目标为导向，努力控制相关费用的增长，以全年净利润目标为关键目标，总体协调控制。

（三）重点工作完成情况

1、落实台集团部署，协助做好游戏、动漫等相关产业在马栏山落地。

完成情况：上半年度，我们积极研究马栏山视频产业园政策，认真梳理久之润资源和优势，探究游戏、动漫产业链，结合AI发展，思考落地方向。二季度起配合芒果超媒策划首届“芒果杯”游戏创新创业大赛，希望借此寻找落地契机。

2、海外游戏发行收入（不含海外代投广告收入）实现1000万元。

完成情况：上半年实现海外游戏相关收入465万，完成全年目标1,000万的46.5%。其中海外《拉米麻将》实现收入286万，同比增长了30%，超预期完成；海外手游定制项目实现收入178万，同比增长了45%。

3、拓展新业务，弹幕游戏上线不低于3个并实现收入400万。在国内外上线新产品不低于2个并实现收入。

完成情况：上半年直播互动娱乐产品上线包括《劲舞之星》、《黄河路保卫战》、《龙王争霸》已达3个，累计实现收入263万，完成全年目标400万的65.9%，全年目标达成可期。另一方面，国内外上线新产品截止上半年末尚未实现正式商业运营收入。

二、上半年不足之处

1、上半年度，我们积极研究马栏山视频产业园政策，认真梳理久之润资源和优势，探索游戏、动漫产业链，并结合AI发展方向思考落地方案。二季度起，配合芒果超媒策划首届“芒果杯”游戏创新创业大赛，希望借此找到合适的落地契机。然而，尽管做了大量准备工作，至今未找到合适的落地机会，导致落实进度较为缓慢，仍需要进一步努力寻找契机以推动项目落地。

2、在次新和新游戏方面，除了《劲舞之星》外，整体表现仍不理想。B部负责的各弹幕小游戏虽然在不断努力尝试，但尚未取得成功项目。其他新游戏如《东方H5》、《红月之契》和《蜡笔小新》等，由于研发进度、版号审批及上线前的不断调整等因素，上线时间晚于预期，不仅上半年未能实现预期收入，还对全年业绩带来了一定的不利影响。

三、下半年工作计划

项目上，久之润将着重围绕以下几个方面开展工作：

1、《劲舞团》系列尤其是端游产品，在总结上半年经验的前提下，下半年将精心策划《劲舞团》城市巡回赛系列活动，进一步提升品牌曝光度，召回老用户，稳定在线人数，确保产品收入。

2、加快业务拓展进度，下半年手游《蜡笔小新家庭派对》预计率先在海外上线，其余新产品也将加快研发和测试进度，力争年底实现国内外上线新游不低于2款。

3、积极研究相关政策，下半年全力配合芒果超媒策划首届湖南“芒果杯”游戏创新创业大赛，希望借此寻找游戏动漫落地马栏山契机。

4、努力开拓海外市场，将游戏产品覆盖至更广泛的海外用户群体，力争实现2024年海外游戏收入超1000万元。

财务上，预计2024年公司全年营收和净利润仍保持与预算目标持平，即收入预计将达4.752亿，净利润为1.355亿。

单位：万元

从最近三年和2024年目标的主要经济指标来看，近三年收入总体基本保持平稳，净利润在后两年有所增长，达到1.3亿元水平。2024年，根据总部要求，净利润目标定在了1.355亿元。目前，我们仍以此作为努力目标。

不过，参照本年上半年的完成业绩情况，同时考虑公司年度季节性因素一般是前高后低（即上半年高于下半年），即使剔除预实比收入中的海外广告代理业务的净额法调整形成的不一致所致的缺失，全年收入的完成会略低于预算目标。同时，净利润的完成度预计要全面完成1.355亿元目标也有一定不确定性。当然，我们会努力向目标靠拢，至少要全力完成原始净利润目标1.26亿元的水平。
