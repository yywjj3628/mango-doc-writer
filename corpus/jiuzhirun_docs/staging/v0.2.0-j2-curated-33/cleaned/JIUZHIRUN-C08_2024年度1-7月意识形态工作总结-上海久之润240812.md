# 意识形态工作总结

2024年度1-7月意识形态工作总结

2024年，上海久之润在电广传媒党委的正确领导下，始终坚持以党的政治建设为统领，坚持党管意识形态不动摇，紧密围绕意识形态工作核心任务，牢牢掌握意识形态主阵地，现将 2024年1-7月份意识形态工作情况报告如下:

久之润2024年1-7月意识形态工作开展情况

1、总部精神贯彻落实情况

上海久之润在电广传媒党委的统一部署下，坚持开展党纪学习教育，进一步加强党员教育管理，始终把党的政治建设摆在首位，以习近平新时代中国特色社会主义思想为指导，教育全体党员干部在政治立场、政治方向、政治原则和政治道路上始终与党中央对标对表。截至目前，本年度累计开展党纪党规学习、党员大会学习7次,主题党日开展学习教育7余次，支部书记讲党课1次。

2、组织领导强化

上海久之润积极响应电广传媒关于意识形态工作要求，将其紧密融入企业经营各环节，全面执行相关工作。明确以总经理顾懿为意识形态分管领导，专员殷文骏负责日常监督。顾懿总经理作为意识形态工作的主要负责人，亲自主持各项工作的开展，充分发挥带头作用，全面推动了意识形态工作的有序开展，有效保障了久之润意识形态领域的安全稳定。

3、《劲舞团》官网及久游官网内容维护

上海久之润高度重视官网及论坛的内容维护工作，确保网络空间的健康有序。通过易盾系统对官网数据进行了自动审查，共计审查数据1,066,743条，成功拦截不通过量14,243条。为进一步强化对违规内容的屏蔽，2024年共计屏蔽了3229条含有国家领导人或涉政敏感词的信息，对179条含有违规信息的账号进行了永久封停及警告处理。同时，客服团队上线查封游戏内违规行为92351例，处理虚假信息277条，确保了游戏环境的纯净。特别是在全国两会及党的二十大三中全会期间，未发现任何违规信息。

4、新媒体账号的维护

截至2024年7月31日，上海久之润现有新媒体账号41个，全部在指定系统完成录入并进行动态监控。新媒体账号的编审和内容发布严格按照《久之润新媒体账号编审制度》进行审核，确保发布内容规范与安全。公司加强了自媒体舆论的监控和维护，及时删除恶意舆论，确保了新媒体平台的健康发展和良好声誉。7月底认真开展了“清朗·网络直播领域虚假和低俗乱象整治”专项行动自查工作，重点检查了虚假营销、伪科普、传播软色情、扰乱社会秩序、欺骗消费者等问题。经自查，未发现上述乱象问题。

二、存在问题

在意识形态工作中，尽管已经取得了一定的成效，但仍需进一步加强对网络环境的检查力度，确保所有内容均符合国家规定和社会主义核心价值观。目前，在内容审查方面还存在机制不够完善的问题，需要持续优化内容审查机制，提高审查效率和准确性。对于新媒体账号的管理，虽已有严格的编审制度，但仍需进一步提高全体员工的意识形态安全意识，确保内容发布的质量，避免因疏忽导致的不当信息传播。

三、下半年工作计划

久之润作为一家党管国有互联网游戏企业，我们深知意识形态工作的重要性。下半年，上海久之润将在电广传媒党委的坚强领导下，持续加强党理论学习，深入贯彻党的二十届三中全会精神，努力将意识形态与企业经营工作的深度融合，聚焦主责主业，提高思想重视程度，营造浓厚的学习氛围，确保意识形态工作与中心工作同频共振。
