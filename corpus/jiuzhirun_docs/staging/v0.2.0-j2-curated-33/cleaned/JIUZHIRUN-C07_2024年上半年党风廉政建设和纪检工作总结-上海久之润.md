# 纪检工作总结

2024年度上半年党风廉政工作总结

2024年上半年，在湖南电广传媒党委的坚强领导下，上海久之润以习近平新时代中国特色社会主义思想为指引，严格落实党风廉政建设责任制。通过深化党纪教育、强化廉洁自律、加强专项整治等多项举措，全面推动党风廉政建设和反腐败斗争，确保了久之润健康、可持续发展。现将上半年的工作总结及下半年工作重点汇报如下：

一、2024年上半年工作总结

1、加强党纪教育，营造廉洁氛围

久之润紧密配合总部纪委要求，扎实推进廉洁文化建设。组织党员领导干部深入学习电广传媒党委关于党风廉政建设和反腐倡廉的讲话及文件，定期转发“党风党纪每日一课”微信帖子，增强党员干部的纪律意识。在中秋、国庆等重要节点，通过发送廉政提醒邮件、张贴宣传标语等形式，营造了风清气正的政治生态。

2、落实“靠企吃企”专项整治工作

根据电广传媒2024年党风廉政建设工作会议要求，久之润认真落实“四个一”系列工作。总经理顾懿通过视频参加党风廉政建设会议，观看警示教育片《靠企吃企的代价2023》，增强了依法合规经营的意识。此外，3月11日，久之润党支部组织开展了主题党日活动，深入学习习近平总书记关于全面从严治党的重要论述，进一步加强了党员干部的理论素养。

3、加强廉洁自律和日常监督

公司持续加强对党员干部的廉洁自律教育，定期开展廉政警示教育活动，强化党员干部的纪律意识和拒腐防变的能力，确保全员严格遵守政治纪律和规矩，营造风清气正的工作氛围。

二、存在问题

党风廉政建设制度落实不到位：党风廉政建设的相关制度执行和落实仍有待加强，部分工作需进一步深化和细化，以从源头上防范腐败问题。

纪检队伍建设需加强：纪检干部的业务能力和理论素养还需提升，以适应新时代纪检监察工作的新要求。

三、下半年工作重点

推进全面从严治党，继续深入学习党的二十大精神，提升全体党员干部的政治站位，加强理论学习，确保全体党员干部坚定不移听党话、跟党走。

深化党风廉政教育，定期开展党风廉政教育活动，通过多种形式增强党员干部的廉洁自律意识，提升廉洁从业的思想自觉。

加强日常监督和专项整治，加大对关键领域和环节的监督检查力度，确保“四风”问题得到有效整治，进一步营造风清气正的政治生态。

加强纪检队伍建设，继续加强纪检干部的培训，提高其理论水平和业务能力，确保纪检监察工作适应新时代要求。

总之，2024年上半年，上海久之润在党风廉政建设方面取得了积极进展。下半年，久之润将继续围绕党的二十大精神，不断加强党的政治建设，深入推进全面从严治党，确保久之润持续稳步发展。
