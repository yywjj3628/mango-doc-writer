# 意识形态工作总结

久之润2024年意识形态工作概要

一、久之润2024年意识形态工作概要

1、总部精神贯彻落实情况

1）坚持以习近平新时代中国特色社会主义思想为指引，确保马克思主义的指导地位。

2）在党支部大会上重点学习意识形态相关内容，引导党员增强“四个意识”，坚定“四个自信”，做到“两个维护”，忠诚拥护“两个确立”。

3）明确以总经理顾懿为意识形态分管领导，专员殷文骏负责日常监督。

4）建立户外广告宣传三审联络名单，加强宣传内容的审核。

2、劲舞团官网及久游官网内容维护

1）通过易盾系统自动审查数据1,066,743条，不通过量14,243条，均已拦截。

2）强化对违规内容的屏蔽，2024年共计屏蔽3229条含有国家领导人或涉政敏感词的信息。对179条含有违规信息的账号进行永久封停及警告处理。

3）客服上线查封游戏内违规行为92351例，处理虚假信息277条。

4）二会期间加强监控，未发现违规信息。

3、新媒体账号的维护

1）上海久之润现有新媒体账号41个，均在指定系统登记备案并动态监控。

2）新媒体账号编审、内容发布严格按照《久之润新媒体账号编审制度》进行审核。

3）自媒体舆论监控和维护，正常舆论日常互动，对恶意舆论进行删除和发布澄清公告。

二、存在问题

1、在意识形态工作中，尽管已经取得了一定的成效，但仍需进一步加强对网络环境的检查力度，确保所有内容均符合国家规定和社会主义核心价值观。

2、需要持续优化内容审查机制，提高审查效率和准确性，减少不当内容的流通。

3、对于新媒体账号的管理，虽已有严格的编审制度，但仍需提高全体员工的意识形态安全意识，确保内容发布的质量。

三、风险研判

1、在当前的网络环境下，意识形态领域可能面临来自不同渠道的风险，包括错误信息的传播和不良舆论的形成。

2、虽然久之润已经采取了有效措施，但仍需警惕可能出现的网络安全问题，如黑客攻击或数据泄露，这些都可能影响久之润的意识形态安全。

四、应对举措

1、加强内部培训，提升员工对意识形态重要性的认识，确保每位员工都能成为意识形态工作的积极参与者。

2、定期评估和更新内容审查系统，确保技术手段与时俱进，有效应对新出现的挑战。

3、增强自媒体账号的管理，确保所有发布的内容都经过严格的审核，符合意识形态方向。
