## 3. 回填脚本说明

### 路径
`scripts/corpus/backfill_lark_base_control_fields.py`

### 功能
1. 用 lark-cli 读取 Base 记录
2. 只处理 clean_status 为空的记录（除非 `--overwrite`）
3. 根据标题、正文、来源推断控制字段
4. 支持 `--dry-run` / `--apply` / `--limit` / `--batch-size` / `--readback` / `--save-plan`

### 推断规则

| 字段 | 规则 |
|------|------|
| clean_status | 标题+正文非空→cleaned；标题或正文空→raw；全空→rejected |
| source_type | 来源含"司情"→weekly_siqing；来源在已知列表→official_account；来源空→internal_doc |
| needs_manual_review | 标题空/正文空/来源空/正文<80字/目录噪音→true |
| split_status | 司情→split；公众号→not_needed；空内容→not_split |
| cleaned_at | clean_status=cleaned 时填写当前时间 |

## 10. B1 Bug 修复

**问题**：`corpus_builder.py` 的 `build_metadata()` 中 `clean_status`、`split_status`、`source_type` 直接用 `fields.get()` 获取，但 lark-cli 返回 select 字段为列表（如 `['cleaned']`），不是字符串。

**影响**：`['cleaned'] != "cleaned"` 导致 strict 模式全部跳过。

**修复**：使用 `extract_first_from_list()` 提取首元素：
```python
clean_status_raw = fields.get("clean_status")
clean_status = extract_first_from_list(clean_status_raw).strip() or None
```
