## 2. 03-plan.md 修改摘要

新增 "generation_mode 感知" 章节，包含：

- **safe_official**：保持 v0.1.3 原规则，不生成扩写指令
- **assisted_expansion**：生成 `controlled_expansion_directives`，指明 allowed_expansions / must_mark_confirmation / forbidden_expansions
- **creative_mimic**：生成 `creative_mimic_directives`，指明 style_mimic_intensity / official_use_allowed=false / draft_disclaimer_required
- **expansion_boundaries**：汇总三种模式的扩写边界

---

## 3. 04-draft.md 修改摘要

新增 "generation_mode 感知与扩写规则" 章节，核心改动：

### safe_official
- 保持 v0.1.3 原行为
- expansion_report 为空数组
- official_use_allowed = true

### assisted_expansion
- 可以扩写：新闻稿/会议稿/汇报材料常见结构、芒果体系表达、战略语汇、产品业务通用表达、领导讲话句式
- 不可以扩写：具体领导、数据、金额、日期、地点、荣誉、会议结论
- 扩写报告分 7 类：style_expansion / structure_expansion / rhetoric_expansion / policy_phrase_expansion / leadership_style_expansion / confirmation_required / unsafe_expansion_warnings
- official_use_allowed = "requires_human_confirmation"

### creative_mimic
- 更强风格仿写，用于内部灵感稿
- 必须输出 draft_disclaimer
- official_use_allowed = false
- 仿写内容标为 style_mimic

---

## 4. 05-review.md 修改摘要

新增 "扩写安全审查" 章节：

- **acceptable_expansion**：可接受扩写（结构句、过渡句、泛化战略表达）
- **unsafe_fabrication**：危险虚构（编领导、编数据、编会议结论）
- **confirmation_required**：需要人工确认（推断的业务背景、称谓、政策口径）
- safe_official 按 v0.1.3 严格审查
- assisted_expansion 不把所有扩写当错误，但必须识别危险虚构
- creative_mimic 必须确认 official_use_allowed=false，检查 draft_disclaimer
- issues type 枚举新增 unsafe_expansion / expansion_not_labeled

---

## 5. 07-quality-score.md 修改摘要

新增 "generation_mode 感知评分" 章节：

| 模式 | 阈值 | fact_safety | mango_style_fit | human_review_required |
|------|:---:|:---:|:---:|:---:|
| safe_official | 8 | 严格 | 按 v0.1.3 | 按 v0.1.3 |
| assisted_expansion | 7 | 严格 | 更重视"像不像" | confirmation_required 时为 true |
| creative_mimic | 6 | 严格 | 不惩罚风格化 | 必须为 true |

新增输出字段：generation_mode / mode_adjusted_threshold / official_use_allowed / expansion_quality_check / draft_disclaimer_check / confirmation_required_check

## 6. Schema 修改摘要

### plan.schema.json

draft_directives 新增（可选）：
- `controlled_expansion_directives`：assisted_expansion 模式扩写指令
- `creative_mimic_directives`：creative_mimic 模式仿写指令

顶层新增（可选）：
- `generation_mode`：当前写作模式
- `expansion_boundaries`：扩写边界汇总

### draft.schema.json

顶层新增：
- `generation_mode`：当前写作模式
- `expansion_report`：扩写报告（7 个子字段）
- `official_use_allowed`：是否允许正式使用（boolean 或 string）
- `draft_disclaimer`：免责声明
- `expansion_policy`：扩写政策声明

draft_policy 新增（可选）：
- `generation_mode` / `expansion_allowed` / `expansion_boundary` / `all_expansions_labeled`

### review.schema.json

顶层新增：
- `generation_mode`：当前写作模式
- `official_use_allowed`：是否允许正式使用
- `expansion_review`：扩写安全审查结果（status / summary / acceptable_expansion / unsafe_fabrication / confirmation_required / expansion_rewrite_instructions）

issues type 枚举新增：
- `unsafe_expansion`：危险虚构扩写
- `expansion_not_labeled`：扩写内容未被标记

### quality_score.schema.json

顶层新增：
- `generation_mode`：当前写作模式
- `mode_adjusted_threshold`：模式调整后阈值
- `official_use_allowed`：是否允许正式使用
- `expansion_quality_check`：扩写质量检查
- `draft_disclaimer_check`：免责声明检查
- `confirmation_required_check`：人工确认项检查
