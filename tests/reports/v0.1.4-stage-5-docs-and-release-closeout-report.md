## 4. v0.1.4 最终能力摘要

### 三种 generation_mode

| 模式 | 阈值 | 扩写 | official_use_allowed | human_review | 用途 |
|------|:----:|:----:|:-------------------:|:------------:|------|
| safe_official | 8.0 | 禁止 | true | 按需 | 正式公文 |
| assisted_expansion | 7.0 | 结构+表达 | requires_human_confirmation | 按需 | 内部草稿 |
| creative_mimic | 6.0 | 全风格仿写 | false | **始终 true** | 灵感参考 |

### Quality Gate 最终规则

- 模式感知阈值：safe_official=8, assisted_expansion=7, creative_mimic=6
- fact_safety / risk_control 严格底线：≥ 8.0，不随模式降低
- overall_pass 必须 boolean true/false，不允许 null
- overall_pass=None 时有 deterministic fallback（基于 scores + threshold 计算）
- 最大返修 2 轮后 warn_and_output
- unsafe_expansion_detected 强制 human_review

### creative_mimic 语义说明

`quality_gate_pass = true` 的含义：**内部灵感稿质量达标**，不是"可以正式发布"。
`official_use_allowed = false` 的含义：**永远不可直接正式发布**。
`human_review_required = true` 的含义：**任何使用都必须人工复核后重写**。

三个标记联合构成 creative_mimic 的安全边界。
