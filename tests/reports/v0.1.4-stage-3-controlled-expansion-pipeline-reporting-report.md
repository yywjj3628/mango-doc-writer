## 2. Pipeline 对 expansion 字段的接入说明

### 字段提取路径

```
draft_result.expansion_report
  ↓ (run_pipeline.py 提取)
PipelineReport.expansion_report_summary (各类型计数)
PipelineReport.confirmation_required_count
PipelineReport.draft_disclaimer

review_result.expansion_review
  ↓ (run_pipeline.py 提取)
PipelineReport.expansion_review_summary (status/计数)
PipelineReport.unsafe_expansion_detected
PipelineReport.unsafe_expansion_warnings

quality_score_result.expansion_quality_check
  ↓ (run_pipeline.py 提取)
PipelineReport.expansion_quality_summary

draft_result.official_use_allowed
  ↓ (run_pipeline.py 提取)
PipelineReport.official_use_allowed (可被覆盖)
```

### 兼容性

- safe_official 下：expansion_report 为空，所有 summary 字段为空/0/false
- 阶段输出中无 expansion 字段时：summary 字段保持默认值
- 不影响 v0.1.3 原有字段

## 5. 模式化质量门禁阈值策略

### 默认阈值（环境变量未设置时）

| 模式 | 默认阈值 |
|------|:---:|
| safe_official | 8.0 |
| assisted_expansion | 7.0 |
| creative_mimic | 6.0 |

### 环境变量覆盖

`QUALITY_GATE_THRESHOLD` 环境变量可覆盖默认阈值。
- 设置时：使用环境变量值
- 未设置时：按 generation_mode 使用默认阈值

### 阈值计算逻辑

```python
MODE_DEFAULT_THRESHOLDS = {
    "safe_official": 8.0,
    "assisted_expansion": 7.0,
    "creative_mimic": 6.0,
}
_env_threshold = os.getenv("QUALITY_GATE_THRESHOLD")
if _env_threshold is not None:
    qg_threshold = float(_env_threshold)
else:
    qg_threshold = MODE_DEFAULT_THRESHOLDS.get(gen_mode, 8.0)
```

## 6. fact_safety / risk_control 严格阈值说明

### STRICT_DIMENSION_MIN = 8.0

fact_safety 和 risk_control 不随模式降低阈值：

| 模式 | 整体阈值 | fact_safety 最低 | risk_control 最低 |
|------|:---:|:---:|:---:|
| safe_official | 8 | 8 | 8 |
| assisted_expansion | 7 | **8** | **8** |
| creative_mimic | 6 | **8** | **8** |

### 强制 human_review_required 场景

以下情况强制 `human_review_required = true`：
1. `fact_safety < 8`
2. `risk_control < 8`
3. `unsafe_expansion_detected = true`
4. `generation_mode = creative_mimic`（始终为 true）

### 实现位置

run_pipeline.py 质量门禁循环中：
```python
strict_violation = False
if fact_safety_score < STRICT_DIMENSION_MIN:
    strict_violation = True
if risk_control_score < STRICT_DIMENSION_MIN:
    strict_violation = True
if report.unsafe_expansion_detected:
    strict_violation = True
```

| 模式 | 策略 |

- quality_rewrite_instructions 使用 "Q" 前缀 issue_id
