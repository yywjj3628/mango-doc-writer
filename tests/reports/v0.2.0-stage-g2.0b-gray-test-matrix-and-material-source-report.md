## 三、素材来源方案

### 1. 真实新素材

| 维度 | 说明 |
|------|------|
| 来源 | 最新司情、会议要点、工作动态、活动素材、用户真实工作输入 |
| 用途 | 部署判断核心样本（真实素材 ≥ 8 篇） |
| 风险边界 | 可用于真实写作，输出仍需人工复核 |
| 优先级 | 最高 |

### 2. 旧司情最小事实化

| 维度 | 说明 |
|------|------|
| 来源 | 已有旧司情、早期每周司情 PDF、已入库 299 篇司情 |
| 处理方式 | 不直接复制原文；抽出最小事实；打散成普通流水账 |
| 用途 | 补足测试覆盖（亮点工作材料、会议新闻、文旅经营、子公司动态） |
| 风险边界 | 可作为灰度测试素材，不作为真实发布事实 |
| 优先级 | 中 |

### 3. 历史事实改写为测试素材

| 维度 | 说明 |
|------|------|
| 来源 | 旧活动、旧会议、旧项目、历史公众号/司情内容 |
| 处理方式 | 可更换日期或简化事实；必须标注"仅用于灰度测试" |
| 用途 | 补齐稀缺文种（工作方案、宣传推文、会议纪要边界） |
| 风险边界 | 不得进入真实发布，只用于系统能力验证 |
| 优先级 | 低 |
