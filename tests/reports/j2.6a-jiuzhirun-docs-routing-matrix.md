## 三、硬过滤规则

| 规则 | 排除条件 | 适用场景 |
|------|---------|---------|
| 普通领导讲话 | not_for_general_leadership_speech=true, rag_usage=reference_only | 活动致辞、总结大会、经营部署 |
| 理论学习发言 | 必须优先 doc_type=理论学习发言, topic=theory_study | 理论学习研讨 |
| 写作风格参考 | 排除 rag_usage=reference_only, rag_usage=hold | 所有写作任务 |
| 对外新闻/司情/宣传 | 排除 jiuzhirun_docs 的 internal 材料作为主要风格 | 司情、公众号 |
| 当前事实 | is_fact_safe=false 只能作结构/风格参考 | 所有任务 |

## 四、环境变量灰度方案

```
# 新增环境变量（默认关闭）
RAG_JIUZHIRUN_ENABLED=false
RAG_JIUZHIRUN_COLLECTION=jiuzhirun_docs_v020_candidate
RAG_JIUZHIRUN_STRICT_FILTER=true
```

- 临时启用：设置 RAG_JIUZHIRUN_ENABLED=true
- 关闭回滚：删除或设为 false
- 不影响旧库：jiuyou_docs 和 mango_style_docs 路由不变
- 记录使用：在 gray-record 中记录 collection 和 filter
