## 四、路由规则实现

| 场景 | 路由 | filter |
|------|------|--------|
| 经营月报 | jiuzhirun_docs | doc_type=经营月报, rag_usage=style_and_reference |
| 年度/半年度总结 | jiuzhirun_docs | doc_type=总结类, 排除 reference_only |
| 党建/纪检/意识形态 | jiuzhirun_docs | 按 topic 精确过滤 |
| 理论学习发言 | jiuzhirun_docs | doc_type=理论学习发言, not_for=true |
| 普通领导讲话 | jiuzhirun_docs | 排除 not_for=true, reference_only, 理论学习 |
| 司情短稿 | mango_style_docs | 不走 jiuzhirun（style_domain=dianguang_siqing 排除） |
| 芒果公众号 | mango_style_docs | 不走 jiuzhirun（style_domain=mango_official_account 排除） |
| 非久之润 | 保持现有路由 | — |

## 七、回滚方式

删除或设为 false：
```
RAG_JIUZHIRUN_ENABLED=false
```

立即回到原路由，不影响 production。
