# J2.7C-Lite 经营月报框架版能力范围冻结报告

> 阶段：J2.7C-Lite
> 日期：2026-06-05
> 状态：✅ 范围冻结完成

---

## 一、用户确认的收缩原因

- 经营月报信息密度高，数据非用户掌握
- 多数表格由财务填写
- 系统不负责财务数据采集和计算
- 优先跑通框架和分析文字生成

---

## 二、第一版能力

| 支持 | 不支持 |
|------|--------|
| 识别经营月报文种 | 财务数据采集 |
| 固定标题和章节顺序 | 13 个表格填报 |
| 表格位置占位 | 同比/环比/预算计算 |
| 接收用户表格/摘要 | 财务逻辑校验 |
| 生成 4 类分析段落 | 历史数据补空 |
| 整理重点工作/下月计划 | 自动推断问题风险 |
| 数字追溯检查 | 正式报送最终月报 |
| 缺失数据标记 | 季度/年末模板切换 |
