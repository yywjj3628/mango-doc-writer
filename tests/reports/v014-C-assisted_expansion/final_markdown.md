# 在公司2025年度工作总结与2026年展望会议上的讲话提纲

同志们：

今天，我们召开公司2025年度工作总结与2026年展望会议，主要任务是全面回顾过去一年的工作，分析当前面临的形势，明确下一阶段的目标任务，动员全体干部员工凝心聚力，推动公司高质量发展。

## 一、认清形势，把握机遇

当前，行业竞争格局深刻变化，文化与科技融合加速演进。我们要清醒认识到机遇与挑战并存，必须保持战略定力，增强忧患意识，以更加主动的姿态迎接变局。

## 二、肯定成绩，增强信心

过去一年，公司各项工作稳步推进，取得了积极进展。

- **游戏业务稳中有进。** 在存量市场中实现了业务韧性和增长潜力。
- **AI赋能内容生产。** 积极探索人工智能与内容创作的深度融合，提升生产效率与创意空间。
- **党建与业务深度融合。** 以高质量党建引领保障高质量发展，将政治优势转化为发展优势。

这些成绩的取得，是全体干部员工团结奋斗、顶压前行的结果。

## 三、部署任务，明确方向

2026年，我们要锚定目标，聚焦重点，抓好以下工作：

- **游戏业务**要持续巩固基本盘，挖掘增量空间，围绕用户需求优化产品与服务。
- **AI赋能**要加快技术应用落地，推动AI工具在内容生产全链条中的深度嵌入，提升创新效率。
- **党建与业务**要进一步深化融合，以党建促业务，以业务强党建，形成良性循环。

## 四、强化保障，狠抓落实

任务已经明确，关键在于落实。各部门要增强责任意识，细化工作举措，确保各项部署落地见效。要加强协同联动，打破壁垒，形成合力。要完善考核机制，以实绩论英雄，营造干事创业的良好氛围。

## 五、结语

同志们，新征程催人奋进。让我们以此次会议为契机，坚定信心、锐意进取，以更加饱满的热情和务实的作风，为推动公司实现更高质量发展而不懈奋斗！

谢谢大家。
