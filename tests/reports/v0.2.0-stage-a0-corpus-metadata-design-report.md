## 5. Metadata Schema 摘要

详见 → `docs/v0.2.0-corpus-metadata-schema.md`

### 核心原则

1. **RAG 只学文风，不当事实源**: `rag_usage` 固定 `"style_only"`，`is_fact_safe` 默认 `false`。
2. **规则库控口径，不自动更新**: `rule_candidate_allowed` 默认 `true`（可萃取候选），但候选不自动成为正式 reference。
3. **历史语料默认不安全**: 所有导入语料 `is_fact_safe=false`，`fact_usage_allowed=false`，`official_reference_allowed=false`。
4. **可追溯**: 每篇 metadata 必须包含 `lark_base_token` + `lark_table_id` + `lark_record_id`。

### 字段分组（7 组，共 30+ 字段）

| 组 | 关键字段 | 数量 |
|----|---------|------|
| 基础标识 | doc_id, corpus_collection, source_type, title | 9 |
| 飞书追溯 | lark_base_token, lark_table_id, lark_record_id | 5 |
| 时间信息 | publish_date, issue_no, synced_at | 6 |
| 清洗状态 | clean_status, content_hash, duplicate_key | 7 |
| RAG 边界 | is_fact_safe, rag_usage, rule_candidate_allowed | 5 |
| 文本统计 | char_count, paragraph_count, language, tags | 6 |
| 审计字段 | audit_status, audit_warnings, schema_version | 3 |

## 6. Base Mapping 摘要

详见 → `docs/v0.2.0-lark-base-to-corpus-mapping.md`

### 当前 Base 字段（6 个基础字段）

标题、来源、备注、正文、概述、时间、链接

### 推荐扩展字段（15 个）

clean_status, split_status, needs_manual_review, source_type, issue_no, tags, doc_type 等

### 两种同步模式

| 模式 | 条件 | 用途 |
|------|------|------|
| **strict** | clean_status 必须存在且 = `"cleaned"` | 生产环境 |
| **bootstrap** | clean_status 不存在时，允许同步（标警告） | Base 尚未升级过渡期 |

### source_type 推断

- 来源含 "司情" → `weekly_siqing`
- 来源含 "芒果日志" → `mango_rizhi`
- 来源含 "飞书" → `feishu_doc`
- 其他 → `manual`
