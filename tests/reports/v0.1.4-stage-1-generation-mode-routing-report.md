## 2. generation_mode 输入解析逻辑

### 结构化 JSON 输入

```python
parse_structured_input(data) → {
    ...,
    "generation_mode": str,           # 校验后的合法值
    "generation_mode_valid": bool,    # 用户输入是否合法
    "generation_mode_warnings": list  # 非法值时的警告信息
}
```

校验流程：
1. 取 `data.get("generation_mode")`
2. None → 默认 `"safe_official"`，valid=True
3. 合法值（`safe_official` / `assisted_expansion` / `creative_mimic`）→ 直接使用
4. 非法字符串 → 回退 `"safe_official"`，valid=False，记录 warning
5. 非字符串类型 → 回退 `"safe_official"`，valid=False，记录 warning

### 自然语言输入

自然语言输入不支持指定 generation_mode，始终默认 `"safe_official"`。

### JSON 字符串输入

先尝试 JSON.loads → 如果成功，按结构化输入处理。

## 3. 默认值策略

| 场景 | 默认值 | valid | warnings |
|------|--------|-------|----------|
| 未提供 generation_mode | safe_official | True | [] |
| 自然语言输入 | safe_official | True | [] |
| 显式指定合法值 | 该值 | True | [] |
| 指定非法值 | safe_official | False | [具体警告] |

---

## 4. 非法值处理策略

**不静默接受**，采取以下策略：

1. 回退到 `safe_official`（安全默认值）
2. 设置 `generation_mode_valid = False`
3. 在 `generation_mode_warnings` 中记录具体警告信息（包含非法值和合法值列表）
4. Pipeline 不会崩溃

示例：
```python
输入: {"generation_mode": "fast_draft"}
输出: {
    "generation_mode": "safe_official",
    "generation_mode_valid": False,
    "generation_mode_warnings": ["generation_mode 值无效 ('fast_draft')，回退到 safe_official。合法值: ['safe_official', 'assisted_expansion', 'creative_mimic']"]
}
```

## 5. Pipeline 传递路径

```
用户输入
  ↓
input_parser.parse_input()  ← 解析 + 校验 generation_mode
  ↓
PipelineInput.generation_mode  ← 存储在 PipelineInput 中
  ↓
run_pipeline._build_stage_payload()  ← 注入到 payload dict
  ↓
_build_stage_prompt()  ← 注入到 Prompt template_vars["generation_mode"]
  ↓
各阶段 Prompt context ({{generation_mode}})  ← 模板变量
```

传递范围：
- classify ✅
- extract ✅
- plan ✅
- draft ✅
- review ✅
- rewrite ✅
- quality_score ✅

safe_official 默认路径与 v0.1.3 等价——所有 Prompt 中的 `{{generation_mode}}` 变量在 safe_official 模式下值为 `"safe_official"`，不影响现有逻辑。

## 6. pipeline_report 新增字段

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `generation_mode` | str | "safe_official" | 当前使用的写作模式 |
| `generation_mode_valid` | bool | True | 用户输入的模式是否合法 |
| `generation_mode_warnings` | list | [] | 非法模式值的警告信息 |
| `official_use_allowed` | bool | True | 是否允许正式使用（creative_mimic=False） |
| `expansion_enabled` | bool | False | 是否启用增强扩写 |

映射规则：

| generation_mode | expansion_enabled | official_use_allowed |
|----------------|:-----------------:|:-------------------:|
| safe_official | false | true |
| assisted_expansion | true | "requires_human_confirmation" |
| creative_mimic | true | false |

pipeline_report.json 序列化示例：
```json
{
  "generation_mode": "assisted_expansion",
  "generation_mode_valid": true,
  "generation_mode_warnings": [],
  "official_use_allowed": "requires_human_confirmation",
  "expansion_enabled": true
}
```

## 7. output_formatter 展示方式

### format_output 返回结构新增

```json
{
  "summary": {
    "generation_mode": "assisted_expansion",
    "generation_mode_valid": true,
    "expansion_enabled": true,
    "official_use_allowed": "requires_human_confirmation"
  },
  "generation_mode_advisory": "⚠️ 当前模式: assisted_expansion（内部草拟/灵感稿），正式使用前需人工确认。",
  "generation_mode_warnings": []
}
```

### format_user_text 展示

- **safe_official 模式**：不显示额外信息，保持简洁
- **assisted_expansion / creative_mimic 模式**：
  - 在正文后显示 `⚠️ 当前模式: xxx（内部草拟/灵感稿），正式使用前需人工确认。`
  - 在摘要行显示 `模式: xxx | 扩写: 启用 | 正式使用: xxx`

## 11. 当前风险点
