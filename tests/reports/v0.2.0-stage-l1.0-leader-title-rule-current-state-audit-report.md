## 六、称谓使用规则草案

### 首次出现
- 姓名 + 完整职务（如"电广传媒党委副书记、总经理付维刚"）
- 多职务按级别排序

### 后续出现
- 可使用姓名（如"付维刚"）
- 可使用"其"指代

### 不同场合
- 新闻稿：首次带职务，后续可简称
- 司情：简短，可省略职务
- 领导讲话：完整职务
- 理论学习发言：可省略职务

### 安全规则
- 职务不确定时标记"待确认"
- 历史职务不得自动使用
- 用户明确信息优先级最高
