## 五、classify prompt 修复

**修复内容**：
- 枚举从 11 种扩展到 15 种
- 新增 4 种文种附带简短判断说明
- 新增「会议新闻 vs 会议纪要判断规则」小节

**新增文种说明**：
- **亮点工作材料**：用于突出阶段亮点、具体举措、成效、经验和下一步。聚焦亮点成效，不全面复盘。
- **宣传推文**：用于公众号/传播类内容，强调传播性但遵守事实边界。区分 style_domain。
- **工作方案**：用于未来工作安排、重点任务、责任分工、时间安排。
- **会议新闻**：用于报道会议发生、主题、主要内容、部署要求、意义和下一步。领导讲话可选。

**会议新闻 vs 会议纪要**：
- 用户要写新闻稿/司情/公众号报道 → 会议新闻
- 用户要整理纪要/议定事项/责任分工/完成时限 → 会议纪要
