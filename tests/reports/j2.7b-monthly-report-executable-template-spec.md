## 二、原始月报正文分析

### 4 份文件性质判断

**结论：这 4 份文件是完成版月报，不是填报模板。**

每份包含：
- 17-18 段人工分析正文（月度分析、累计分析、资产负债分析、现金流分析等）
- 5 段固定说明文字
- 16-21 个数据表格

### 人工正文可学习性

**结论：存在足够高质量的人工分析段落，适合 RAG 学习。**

典型分析段落：
- "1月收入5,092.99万，预算完成率为105.00%，其中劲舞团端游组同比/环比分别下降/增长了1.31%/33.64%..."
- "本年累计收入9,378.20万，预算达成率为105.22%，收入预算达成主要归因于劲舞团端游组..."
- "流动资产与期初比增长10.49%，主要是本年收益带来的货币资金增长..."

### 适合模型生成的段落

- 月度收入分析（根据数据生成）
- 累计收入分析（根据数据生成）
- 资产负债分析（根据数据生成）
- 现金流分析（根据数据生成）

### 必须用户提供事实后才能生成

- 本月重点工作
- 问题与风险
- 下月计划

## 四、计算公式

| calculated_field | formula | rounding | 证据 | needs_confirmation |
|-----------------|---------|----------|------|-------------------|
| 同比增减额 | 本月完成 - 上年同期 | 2位小数 | 表格直接显示 | false |
| 同比增长率 | (本月完成 - 上年同期) / 上年同期 | 2位小数+% | 表格直接显示 | false |
| 环比增减额 | 本月完成 - 上月 | 2位小数 | 表格直接显示 | false |
| 环比增长率 | (本月完成 - 上月) / 上月 | 2位小数+% | 表格直接显示 | false |
| 预算差异 | 实算 - 预算 | 2位小数 | 表格直接显示 | false |
| 预算完成率 | 实算 / 预算 | 2位小数+% | 表格直接显示 | false |
| 累计预算完成率 | 累计完成 / 累计预算 | 2位小数+% | 表格直接显示 | false |
| 年度预算进度 | 累计完成 / 年度预算 | 2位小数+% | 表格直接显示 | false |
| 投资完成率 | 实际投资 / 计划投资 | 2位小数+% | 表格直接显示 | false |
