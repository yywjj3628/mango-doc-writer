**结论**：汇报材料、报告、请示、通知、函、会议纪要直接调用 jiuyou_docs；其他文种通过 fallback 进入。

## 五、事实安全边界

1. ✅ jiuyou_docs 可以用于学习结构、风格、历史脉络和经营材料表达
2. ⚠️ 历史经营数据不能自动作为当前事实使用
3. ⚠️ 工作计划、目标责任书中的目标不能写成已完成成果
4. ⚠️ 历史领导职务不能自动视为现任职务
5. ⚠️ 新稿的当期数据、实际成果和当前领导职务必须由用户输入或人工确认
6. ⚠️ 建议历史材料统一设置 is_fact_safe=false

## 六、后续架构建议

### 方案 A：继续使用现有 jiuyou_docs，仅补 metadata

- **优点**：改造成本低，不影响现有 pipeline
- **风险**：metadata 不完整，无法精准检索
- **改造成本**：低
- **推荐**：短期可用

### 方案 B：从源文件重建 jiuzhirun_docs candidate（推荐）

- **优点**：metadata 完整，可精准检索
- **风险**：需要重新构建，有过渡期
- **改造成本**：中
- **推荐**：中期推荐

### 方案 C：保留 jiuyou_docs，同时建立独立 jiuzhirun_docs

- **优点**：不影响现有系统，新旧并行
- **风险**：维护两套系统
- **改造成本**：高
- **推荐**：长期方案
