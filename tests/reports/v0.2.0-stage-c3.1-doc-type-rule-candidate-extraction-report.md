## 三、5 条候选摘要

### 1. 亮点工作材料

- **结构**：背景 → 主要亮点 → 具体举措 → 阶段成效 → 经验启示 → 下一步计划
- **必须元素**：标题、至少3个亮点、数据支撑、阶段成效
- **篇幅**：600-900字（司情），1000-1500字（集团级）
- **与现有文种区分**：聚焦亮点成效 vs 总结全面复盘 vs 汇报含分析

### 2. 宣传推文

- **结构**：传播性标题 → 活动导语 → 现场/亮点 → 主体价值 → 意义提升 → 行动/展望
- **必须元素**：传播性标题、活动/事件核心、价值提炼
- **篇幅**：500-800字（司情），800-1200字（公众号）
- **与现有文种区分**：侧重传播性情感共鸣 vs 新闻稿侧重事实陈述

### 3. 工作方案

- **结构**：背景依据 → 总体目标 → 重点任务 → 责任分工 → 时间安排 → 保障措施
- **必须元素**：背景依据、总体目标、重点任务、责任分工、时间安排
- **篇幅**：1500-3000字
- **与现有文种区分**：侧重未来规划执行 vs 汇报/总结/通知

### 4. 会议新闻

- **结构**：传播性标题 → 导语 → 会议亮点 → 领导讲话 → 意义 → 展望
- **必须元素**：传播性标题、会议主题、领导讲话要点、会议意义
- **篇幅**：500-800字（司情），800-1200字（集团级）
- **与现有文种区分**：新闻报道 vs 会议纪要记录议定事项

### 5. 会议纪要边界补充

- **补充内容**：与会议新闻的边界说明
- **判断关键词**：议定/决议/同意 → 纪要；召开/出席并讲话/强调 → 会议新闻
- **禁止元素**：新闻导语、传播性标题、情感表达、意义升华

## 五、会议新闻 vs 会议纪要边界说明

| 维度 | 会议新闻 | 会议纪要 |
|------|---------|---------|
| 目的 | 新闻报道，传播会议亮点 | 记录议定事项，内部流转 |
| 标题 | 传播性 | 概括式 |
| 语气 | 新闻报道风格 | 记录、执行风格 |
| 核心内容 | 亮点、领导讲话、意义 | 决议、责任分工、时限 |
| 禁止 | 逐条罗列议程、纪要口吻 | 新闻导语、情感表达 |
| 关键词 | 召开、出席并讲话、强调、要求 | 议定、决议、同意、责任分工 |
