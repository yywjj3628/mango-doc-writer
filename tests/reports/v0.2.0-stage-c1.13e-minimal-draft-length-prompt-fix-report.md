## 一、修改内容

### 04-draft.md（新增 §2.1 篇幅遵循规则）

在"结构必须服从 plan_result"和"事实必须服从 extract_result"之间新增一段：

- 如果 requirement / draft_directives 中包含目标篇幅，正文应尽量达到目标下限
- 司情普通新闻稿/子公司动态/活动短讯允许短小精悍，不机械拉长
- 领导讲话/汇报材料/亮点工作/宣传推文/long 模式应充分展开
- 不得为凑字编造姓名、职务、数据、时间、地点
- 素材不足时保持事实安全，在 warnings 中说明

### 06-rewrite.md（新增 §4.1 不得无理由压缩已达标正文）

- 如果 draft 阶段正文已达到目标篇幅，rewrite 不得无理由压缩
- 如果必须删减，优先删除重复空话，不删除核心事实和必要展开

## 三、结论

### B. ⚠️ prompt 修复有改善但仍偏短，建议增加 --model 灰度模型切换

- prompt 约束确实让模型写得更长了（+15-17%）
- 但 flash 模型的输出长度有天花板，prompt 约束只能推到一定程度
- 如果需要更长输出，需要探索 draft-only pro 或更强的模型

**建议下一步**：
- 进入 C1.13F：run_gray.py 增加 `--model` 参数支持灰度模型切换
- 或探索"只在 draft 阶段用 pro，其他阶段用 flash"的混合方案
