## 二、Metadata Schema

**必填字段**：schema_version, doc_id, title, filename, organization, organization_scope, source_family, doc_type, topic, style_domain, rag_usage, is_fact_safe, sensitivity_level, source_status

**关键枚举**：
- doc_type：经营月报/年度总结/半年度总结/工作计划/党建工作总结/纪检工作总结/意识形态工作总结/领导讲话/理论学习发言/目标责任书/经营分析材料/其他
- topic：business_operation/annual_summary/work_planning/party_building/discipline_inspection/ideology/leadership_speech/theory_study/headquarters_requirement/other
- rag_usage：style_and_reference/style_only/reference_only/hold
- sensitivity_level：normal/internal/sensitive/restricted
- source_status：historical/current_confirmed/superseded/unknown

---

## 三、事实安全规则

1. 历史材料统一 is_fact_safe=false
2. 历史经营数据不得自动用于新稿
3. 历史工作计划和目标不得写成已完成成果
4. 历史领导职务不得自动视为现任职务
5. 写新稿时，当期数据和实际成果必须由用户输入
6. 顾懿相关讲话可学习表达、身份姿态和结构，但具体会议主题与要求必须来自当前素材
7. sensitive/restricted 材料默认不得进入候选库
8. reference_only 材料不得主导写作风格
