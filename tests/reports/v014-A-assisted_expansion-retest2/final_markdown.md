# 芒果超媒举办AI内容创作大赛 《AI导演》获一等奖实现全流程AI辅助制作

4月15日，芒果超媒举办AI内容创作大赛。来自12支团队的参赛作品经过激烈角逐，一等奖作品《AI导演》脱颖而出，实现了全流程AI辅助制作。

本次大赛聚焦AI内容创作领域，12支团队围绕技术创新与应用展开比拼，展现了芒果体系在人工智能与内容融合方面的积极探索。

一等奖作品《AI导演》实现了全流程AI辅助制作。该作品展示了AI在内容生产中的应用前景。

此次大赛是芒果超媒推动“文化+科技”深度融合的重要举措，通过以赛促创、以赛聚才，进一步激发内部创新活力，为构建数智化平台型媒体集团蓄势赋能。

未来，芒果超媒将持续深化AI技术应用，以融合创新激活发展动能，加速从工具应用到智媒跃升的进程。
