# 芒果超媒举办AI内容创作大赛——一等奖作品《AI导演》实现全流程AI辅助制作

4月15日，芒果超媒举办AI内容创作大赛。来自12个参赛团队围绕AI内容创作展开角逐，生动展示了芒果系在文化与科技融合领域的创新活力。

大赛以AI内容创作为主题，吸引了12支优秀团队参与，参赛作品涵盖智能制作、虚拟人交互、AI编剧等多个方向。经过激烈角逐，一等奖作品《AI导演》脱颖而出，实现了全流程AI辅助制作，从剧本生成、分镜设计到后期剪辑均由AI高效协同完成，充分体现了“AI+”在内容生产中的深度应用。

此次大赛不仅是芒果超媒在人工智能领域的一次重要探索，也是推动内容与技术双前锋融合的具体实践。芒果超媒始终致力于以科技赋能内容，通过AI内容创作大赛激活内部创新动能，为行业智媒跃升注入新活力。

以此次大赛为契机，芒果超媒将继续深化AI技术在全内容链中的应用，携手更多创作者，定义下一代内容工业的未来。
