## 六、发现的额外问题

### 问题 A：gray-record 中 final_markdown 永远显示 ❌（低优）

gray-record 检查 `report.get("final_markdown")`，但 `pipeline_report.json` 不包含此字段——`final_markdown` 保存为独立文件 `final_markdown.md`。

这是 pre-existing 问题，不在 C1.9E 修复范围内。

### 问题 B：gray-record 中 QG 分数显示为空 `{}`（低优）

gray-record 读取 `report.get("quality_gate", {}).get("score", {})`，但 pipeline_report.json 中 QG 分数存储为 `final_quality_scores`（平铺字段），不是嵌套在 `quality_gate.score` 中。

同样是 pre-existing 问题。

### 问题 C：draft 阶段 JSON 解析偶发失败

Case 2 的 draft 阶段第一次调用 JSON 解析失败（`Expecting ',' delimiter`），重试后成功。这是 DeepSeek 模型输出不稳定的表现，与 C1.9E 修复无关，但 assisted_expansion 的长 prompt 可能增加了 JSON 格式错误概率。
