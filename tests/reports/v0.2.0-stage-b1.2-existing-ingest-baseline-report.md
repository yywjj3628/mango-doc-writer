## 5. Duplicate Key 规则

### primary_duplicate_key
`normalized(title) + source + publish_date`

### secondary_duplicate_key
`normalized(title) + content_hash_prefix(前16位SHA256)`

### fallback_duplicate_key
`normalized(title)` alone

### normalized(title) 规则
- 去空格（半角 + 全角）
- 统一中英文标点（：→:，，（→, 等）
- 保留原文内容，不截断

### content_hash 规则
- 对正文去空格后取前 2000 字符
- SHA256 取前 16 位
