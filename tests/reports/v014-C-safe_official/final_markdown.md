# 在公司年度总结会上的讲话

同志们：

今天，我们召开公司年度总结会，回顾2025年度工作，展望2026年发展。在此，我代表公司向全体员工的辛勤付出表示衷心感谢。

## 一、认清形势，统一思想

当前，行业竞争格局深刻变化，文化与科技融合加速推进。我们要清醒认识到，机遇与挑战并存。过去一年，公司游戏业务稳中有进，展现出良好的发展韧性；AI赋能内容生产、党建与业务深度融合等方向也取得了积极进展。这些为我们应对2026年新形势奠定了坚实基础。

## 二、肯定成绩，坚定信心

2025年，在全体员工的共同努力下，公司各项工作扎实推进。游戏业务保持稳中有进的良好态势；AI赋能内容生产稳步推进，为内容创新注入新动能；党建与业务深度融合也取得积极进展。这些成绩的取得，凝聚了大家的智慧与汗水。

## 三、明确任务，重点部署

展望2026年，我们要聚焦以下重点方向：

一是持续巩固游戏业务基本盘，推动稳中有进再上新台阶。要深耕精品内容，拓展用户群体，提升运营效率。

二是加快推进AI赋能内容生产。深化人工智能在内容策划、制作、分发等环节的应用，打造具有核心竞争力的智能内容生态。

三是促进党建与业务深度融合。以党建引领业务发展，将党的政治优势转化为发展优势，确保各项工作沿着正确方向前进。

## 四、强化保障，狠抓落实

各部门要压实责任，细化任务，确保各项工作部署落地见效。要加强协同配合，形成工作合力。要完善考核机制，以实绩论英雄。

## 五、凝心聚力，再启新程

同志们，2026年的征程已经开启。让我们以更加饱满的热情、更加务实的作风，奋力开创公司发展新局面！

谢谢大家！
