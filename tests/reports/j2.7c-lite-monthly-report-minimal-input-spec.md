# J2.7C-Lite 经营月报最小输入规格

> 日期：2026-06-05

---

## 输入字段

### 必填（3 个）

| 字段 | 类型 | 说明 | 示例 |
|------|------|------|------|
| reporting_period | string | 报告期间 | "2026年4月" |
| monthly_work_facts | string | 本月重点工作事实 | "完成XX项目上线，推进XX工作" |
| next_month_plan | string | 下月计划事实 | "计划推进XX，启动XX" |

### 可选（7 个）

| 字段 | 类型 | 说明 |
|------|------|------|
| financial_tables_or_summary | string | 已填写表格或表格摘要 |
| monthly_revenue_analysis_facts | string | 月度收入分析事实 |
| cumulative_analysis_facts | string | 累计收入分析事实 |
| balance_sheet_analysis_facts | string | 资产负债分析事实 |
| cash_flow_analysis_facts | string | 现金流分析事实 |
| issues_and_risks | string | 问题与风险 |
| report_date | string | 报告日期 |

### 允许输入形式

- 已填写月报 Word/PDF
- 已填写表格
- 表格摘要
- 用户粘贴的关键数据和事实

### 缺失处理

- 没有财务表格 → 保留表格占位，不生成数字分析
- 没有问题与风险 → 不显示该章节
- 没有分析事实 → 不自行推断
