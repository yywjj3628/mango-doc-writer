## 6. Sync 脚本调整

### 6.1 新增 `--exclude-manual-review` 参数

- `corpus_builder.py`: `should_process()` 和 `build_corpus()` 新增 `exclude_manual_review` 参数
- `sync_from_lark_base.py`: 新增 `--exclude-manual-review` CLI 参数并传递给 `build_corpus()`
- 行为：strict 模式下，`needs_manual_review=true` 的记录直接跳过（`manual_review_excluded`）

### 6.2 重构字段解析

- **问题**：原 `DATA_INDEX_MAP` 硬编码 7 个旧字段索引，Base schema 扩展到 24 字段后 lark-cli 返回的 `field_id_list` 顺序变化
- **方案**：`parse_row_to_record()` 改为动态映射，使用 `field_id_list` + `FIELD_ID_TO_NAME` 字典
- **验证**：bootstrap 模式 dry-run 3 条全部正确解析

### 6.3 更新 `OPTIONAL_FIELDS`

新增：`source_url`, `raw_file_token`, `cleaner`, `sync_status`, `last_synced_at`
