# 芒果超媒举办AI内容创作大赛 12个团队参赛 《AI导演》获一等奖

4月15日，芒果超媒股份有限公司举办AI内容创作大赛。大赛吸引了12个团队参赛，经过激烈角逐，一等奖作品《AI导演》脱颖而出，实现了全流程AI辅助制作。

本次大赛以AI内容创作为主题，聚焦人工智能在内容生产中的创新应用，旨在激发团队创作活力，探索AI与内容深度融合的新路径。参赛作品涵盖AI编剧、AI剪辑、AI特效等多个方向，展现了芒果超媒在智媒领域的积极探索。

一等奖作品《AI导演》凭借全流程AI辅助制作技术赢得评审青睐，标志着AI技术在内容创作领域迈出重要一步。该作品从创意策划、脚本生成到后期制作，均由AI深度参与，实现了效率与创意的双重突破。

大赛的举办，是芒果超媒推动“文化+科技”融合、践行“智媒跃升”战略的重要举措。通过以赛促创，加速AI技术落地应用，为构建数智化内容生态注入新动能。

未来，芒果超媒将持续深耕AI内容创作领域，以融合创新激活发展动能，在服务大局中找准坐标，探索更多AI赋能内容生产的可能性。
