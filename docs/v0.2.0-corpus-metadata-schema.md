# v0.2.0 Corpus Metadata Schema

> **版本**: v0.2.0  
> **适用范围**: mango_style_docs corpus 全部语料  
> **原则**: RAG 只学文风，不当事实源；规则库控口径，不自动更新；历史语料默认 is_fact_safe=false。

---

## 1. 总览

每篇语料包含 3 个本地文件：

| 文件 | 路径 | 格式 |
|------|------|------|
| 正文 Markdown | `corpus/mango_style_docs/cleaned/{doc_id}.md` | MD + YAML front matter |
| Metadata JSON | `corpus/mango_style_docs/metadata/{doc_id}.meta.json` | JSON |
| Manifest 行 | `corpus/mango_style_docs/manifests/manifest-v0.2.0.jsonl` | JSONL（追加写入） |

---

## 2. 字段定义

### 2.1 基础标识

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `doc_id` | string | ✅ | 唯一标识，格式: `{source_type}_{date}_{hash8}` 或 `{source_type}_{year}_issue{N}_{seq}` |
| `corpus_collection` | string | ✅ | 固定值 `"mango_style_docs"` |
| `source_type` | string | ✅ | 来源类型: `siqing` / `mango_rizhi` / `feishu_doc` / `web` / `weixin` / `manual` |
| `source` | string | ✅ | 来源名: 如 `"湖南广播电视台办公室"`, `"芒果日志公众号"` |
| `title` | string | ✅ | 语料标题 |
| `summary` | string | ❌ | 内容摘要（可选） |
| `body_md_path` | string | ✅ | 正文 Markdown 相对路径: `cleaned/{doc_id}.md` |
| `meta_json_path` | string | ✅ | Metadata JSON 相对路径: `metadata/{doc_id}.meta.json` |

### 2.2 飞书 Base 追溯

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `lark_base_token` | string | ✅（从 Base 同步时） | 飞书多维表格 app_token |
| `lark_table_id` | string | ✅（从 Base 同步时） | 数据表 ID |
| `lark_record_id` | string | ✅（从 Base 同步时） | 记录 ID |
| `lark_view_id` | string | ❌ | 视图 ID（如有） |
| `lark_record_url` | string | ❌ | 记录链接（如有） |

> ⚠️ 任何语料的 metadata 都必须能追溯到其来源（Base record_id 或手动导入记录）。

### 2.3 时间信息

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `publish_date` | string | ✅ | 发布日期 ISO 8601: `"2024-09-26"` |
| `issue_date` | string | ❌ | 期刊日期（司情等期刊类资料） |
| `issue_no` | integer | ❌ | 期号 |
| `total_issue_no` | integer | ❌ | 总期号 |
| `extracted_at` | string | ❌ | 从原始材料提取的时间（ISO 8601） |
| `synced_at` | string | ✅ | 同步到 VPS corpus 的时间（ISO 8601） |

### 2.4 清洗状态

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `clean_status` | string | ✅ | `cleaned` / `raw` / `needs_review` / `rejected` |
| `split_status` | string | ❌ | `not_split` / `split_done` / `split_needs_review` |
| `needs_manual_review` | boolean | ✅ | 是否需人工复核 |
| `manual_review_reason` | string | ❌ | 人工复核原因（如 needs_manual_review=true） |
| `content_hash` | string | ✅ | 正文 SHA-256 hex（不含 front matter） |
| `duplicate_key` | string | ✅ | 去重键: `{source}_{title}_{publish_date}` |

### 2.5 RAG 使用边界

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|------|------|
| `is_fact_safe` | boolean | ✅ | `false` | 历史/导入语料默认 false，仅经人工确认后可设为 true |
| `rag_usage` | string | ✅ | `"style_only"` | 固定值，仅用于风格学习 |
| `fact_usage_allowed` | boolean | ✅ | `false` | 是否可用于事实引用，默认禁止 |
| `rule_candidate_allowed` | boolean | ✅ | `true` | 是否可用于候选规则萃取 |
| `official_reference_allowed` | boolean | ✅ | `false` | 是否可作为正式 reference，默认禁止 |

### 2.6 文本统计

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `char_count` | integer | ✅ | 正文字符数（不含 front matter） |
| `paragraph_count` | integer | ✅ | 段落数（`\n\n` 分隔） |
| `language` | string | ✅ | 语言代码: `"zh"` / `"zh-CN"` |
| `tags` | string[] | ❌ | 标签 |
| `doc_type` | string | ❌ | 文档类型: `新闻稿` / `领导讲话` / `通报` / `党建材料` / `活动稿` |
| `topic` | string | ❌ | 主题分类 |

### 2.7 审计字段

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `audit_status` | string | ✅ | `pending` / `passed` / `warning` / `failed` |
| `audit_warnings` | string[] | ✅ | 审计警告列表（可为空数组 `[]`） |
| `schema_version` | string | ✅ | 固定值 `"v0.2.0"` |

## 4. doc_id 生成规则

### 格式

```
{source_type}_{date}_{hash8}
```

示例:
- `siqing_2024-09-26_8f3a12c4`
- `mango_rizhi_2025-09-08_a1b2c3d4`

### 特殊格式（期刊类）

如果 Base 记录提供 `issue_no` / `total_issue_no` / `row_index`:

```
{source_type}_{year}_issue{issue_no}_{row_index_pad3}
```

示例:
- `siqing_2024_issue139_001`

### 生成逻辑

1. **有 issue_no**: 优先使用 `{source_type}_{year}_issue{N}_{seq:03d}`
2. **有 publish_date**: `{source_type}_{date}_{sha256(title+date)[:8]}`
3. **Fallback**: `{source_type}_{sha256(title+source)[:8]}`

### 文件名安全

- 只允许: 字母、数字、`_`、`-`、`.`
- 移除所有空格、斜杠、特殊字符
- 总长度 ≤ 100 字符

## 5. content_hash 计算

```python
import hashlib

def compute_content_hash(body_text: str) -> str:
    """计算正文内容的 SHA-256 hash（不含 front matter）"""
    return hashlib.sha256(body_text.encode("utf-8")).hexdigest()
```

---

## 6. duplicate_key 计算

```python
def compute_duplicate_key(source: str, title: str, publish_date: str) -> str:
    """生成去重键"""
    return f"{source}|{title}|{publish_date}"
```

## 7. 审计警告类型

| Warning | 严重级别 | 说明 |
|---------|---------|------|
| `missing_title` | ❌ fatal | 缺少标题，不同步 |
| `missing_body` | ❌ fatal | 缺少正文，不同步 |
| `missing_publish_date` | ⚠️ warning | 缺少发布日期 |
| `missing_clean_status_bootstrap` | ⚠️ info | bootstrap 模式下缺少 clean_status |
| `body_too_short` | ⚠️ warning | 正文 < 50 字符 |
| `duplicate_key_collision` | ⚠️ warning | duplicate_key 重复 |
| `needs_manual_review` | ⚠️ info | 标记需要人工复核 |
| `source_not_allowed` | ❌ fatal | 不允许的来源类型 |
| `rag_usage_not_style_only` | ❌ fatal | rag_usage 不等于 style_only |

## 9. 安全约束

- ❌ metadata **不得**包含 API key、token secret、用户隐私密钥
- ❌ metadata **不得**包含完整的 access_token
- ✅ `lark_base_token` / `lark_record_id` 等为业务标识符（非密钥），允许包含
- ✅ `lark_record_url` 为飞书内部链接，允许包含
